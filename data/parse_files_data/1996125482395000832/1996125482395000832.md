# 重庆高速公路集团有限公司法律审核工作指引  

为规范有效开展法律审核工作，发挥法律服务监督职能，提高法律风险防范控制能力，明确法律审核范围、工作部门、方式以及程序等，根据上级政策要求，结合集团实际，制定本指引。  

# 一、政策依据  

1．国务院国资委《中央企业全面风险管理指引》《关于落实省属国有重点企业法制工作第三个三年目标有关事项的通知》重庆市国资委《关于在全市国有及国有控股企业规范使用<企业法律顾问法律意见书>的通知》以及关于企业“三项重点工作（规章制度、重要决策及经济合同）法律审核要求等。  

2．集团《"三重一大”事项集体决策实施办法》《制度管理办法》《法律事务管理办法》《合同管理办法》  

# 二、审核范围  

1．集团规章制度、重要决策及经济合同;  

2．法律、法规、制度要求法律意见为必备要件的;  

3．集团领导交法务审计部（或外聘法律顾问单位）法律审核把关事项。  

# 三、工作部门  

1．送审部门  

依据政策制度规定提出法律审核要求的集团各部门、中心为送审部门。  

送审部门负责提供法律审核所需业务信息资料，对法律审核意见采纳情况进行确认。  

# 2．审核部门  

法务审计部为集团法律审核部门；子分公司、独立经营的中心所属法务部门或法务工作职责所在部门为子分公司、中心法律审核部门。  

法务部门独立或委托外聘常年法律顾问单位开展法律审核工作。  

集团外聘法律顾问单位的法律审核结论，由法务审计部签署意见；未设置法务部门的子分公司、中心，有关外聘法律顾问单位审核结论，由法务工作职责所在部门签署意见。  

法务审计部受理送审事项后及时确定审核承办人，并告知送审部门，送审部门指定专人与审核承办人沟通协作。  

3．子分公司、独立经营的中心提交的重大事项需法律审核的，应按集团《法律事务管理办法》有关规定，参照本条第2款及送审单位规定，独立完成法律审核，集团可不另行法律审核。但以下情况除外：  

（1）集团领导认为有必要再次法律审核的，由集团对应牵头管理部门送审;  

（2）法务审计部发现子分公司、中心的法律审核不全面、存在重要遗漏、重大偏差等问题认为有必要再次法律审核的，直接联系集团对应牵头管理部门及子分公司;  

（3）子分公司、独立经营的中心尚未聘请法律顾问单位也未设置法律事务岗位，需法务审计部提供法律协助的，由子分公司、中心向法务审计部提出申请。  

# 四、审核方式  

1．经合同、事务签报立项流程签署意见;  

2．参加会议发表意见 (或建议);  

3．电子邮件、来往函件;  

4．口头交流建议;  

5．专项法律审核意见。  

集团经济合同，一般在合同立项流程中进行法律审核，如需要进行专项法律审核的，按照本指引第四条有关规定办理  

对于事实清楚、法律关系简单、需要快速解答，或者业务部门提出口头咨询的事项，可当面口头或电话答复。  

经营管理重大事项，或依据政策法规规定、规章制度要求，应出具专项法律审核意见的，出具专项审核意见。  

# 五、送审和审核程序  

# 1．送审  

业务部门根据实际需要以口头、书面或电子公文等形式向法务审计部提出法律审核要求。  

需要进行专项法律审核的，应事前填写《法律事项审核流程表》（经协同办公网，样式见附件）送审，相关材料一并送交。  

提出法律审核要求应明确具体、有针对性，对送审理由、业务背景、各方争议或关注的焦点等进行说明，提供业务事项信息资料，并指定联系人与审核经办人保持联系。送审部门对所提供资料信息的真实性、完整性负责。  

# 2．审核  

法务审计部核实送审事项是否属于法律审核事项范畴，对事项审核的合法性负责。在合法性审核的基础上，努力提高审核质量，扩大审核面，促进法务工作与业务工作的融合。  

法律审核应尊重基本法律事实、严格依法、审慎及时。专项审核意见应一事一议、格式规范、逻辑严密、程序严谨、紧扣要求。  

不属于法律审核事项的应在送审后2个工作日内回复;属于法律审核事项的，应在收齐资料后5个工作日内出具法律审核意见 (或建议)。  

# 3．确认  

业务部门结合业务特点、需求、理论意见与实际业务的匹配度等，确定法律审核意见（或建议）是否采纳执行，不采纳的应说明理由，并向集团分管领导报告。  

# 4．归档  

送审部门对法律审核意见及审核流程资料归档保存。

# 专项法律审核意见应考虑内容  

（1）出具法律意见的背景和信息资料来源（包括由业务部  
门提供的资料、口述信息等)（2）为出具法律意见所查阅和依据的相关法律规定、文件  
资料;（3）对需要论证的事项或事务进行阐述和分析;(4）结论 (意见或建议);（5）企业法律部门（或法律顾问）认为需要说明或明确的  
事项。(6）企业法律部门（或者法律顾问）签章。
