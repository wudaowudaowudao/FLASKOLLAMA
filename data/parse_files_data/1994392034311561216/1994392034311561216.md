# 6几何模型处理  

# 6.1模型简化  

a）模型简化以不影响结构刚度为原则。  
b）模型简化后须反映产品实际结构的主要特征及连接关系。  
c）简化时保留传力路径的关键结构，主次清晰。  
d）对于结构及载荷均对称于某一平面时，可利用对称性质简化模型。  

# 6.2摇枕、侧架、副构架、制动梁、摇动座、轴箱、弹簧托板  

应对半径较小的倒圆角、小孔及间距较小的小特征线进行清除。摇枕、侧架、摇动座可利用对称性质(结构和载荷均对称)简化模型。  

# 6.3构架  

构架的仿真模型包含侧梁、横梁、纵向梁、心盘、旁承、一系簧座等所有的主要构件，及构架结构上需要施加载荷或约束的转向架构架设备连接装置。对构架局部结构强度及刚度影响较大的结构，应按照实际结构建立模型。对构架整体刚度、强度影响较小的结构可进行简化，如管路及其吊座、没有载荷的小支座等。  

# 7材料属性设置  

转向架常用材料为金属材料。  

材料属性按照相关的标准及技术条件选取，新材料的力学性能建议通过材料力学性能试验取得，推荐采用实测的最低值。常用材料性能包括密度、弹性模量、剪切模量、泊松比、屈服强度、抗拉强度、延伸率等。  

# 8有限元网格划分  

转向架部件常用单元类型及应用部位参照附录A.1执行。  

# 8.1摇枕  

摇枕推荐采用低阶四节点四面体实体单元进行网格划分，单元尺寸推荐整体采用 $5\sim8\mathrm{{mm}}$ ，局部细节特征最小采用 $3\mathrm{mm}$ o  

垂向（Z向）支撑位置推荐使用多点约束和弹簧单元模拟。弹簧刚度按照实际刚度选取。摇枕横向（转向架坐标系X向）支撑在摇枕端部侧面之间使用多点约束模拟。  

# 8.2侧架  

侧架推荐采用低阶四节点四面体实体单元进行网格划分，单元尺寸推荐整体采用 $5\sim8\mathrm{{mm}}$ ，局部细节特征最小采用 $3\mathrm{mm}$ o  

侧架端部垂向（Z向）支撑使用多点约束模拟，多点约束中心节点位于车轴中心线上，横向位置位于侧架横向中心。横向（Y向）支撑在侧架端部，横向接触面推荐使用多点约束模拟，位于横向加载侧的对侧。  

# 8.3副构架  

副构架推荐采用低阶四节点四面体实体单元进行网格划分，单元尺寸推荐整体采用 $5\sim8\mathrm{{mm}}$ ，局部细节特征最小采用 $3\mathrm{mm}$ o  

副构架与承载鞍之间通过弹性接触和带有预紧力的梁单元连接。两侧承载鞍之间通过梁单元模拟轮对连接。模拟销钉和交叉杆用梁单元模拟，梁单元端部与副构架上孔内部圆柱面上各节点进行位移耦合。  

# 8.4制动梁  

制动梁推荐采用低阶四节点四面体实体单元进行网格划分，单元尺寸推荐整体采用 $3\sim5\mathrm{mm}$ 。

# 8.7构架

# 9边界条件施加  

# 9.1载荷  

# 9.1.1一般原则  

根据转向架各部件实际受载情况，确定载荷方式和大小。  

# 9.1.2转向架部件常用载荷  

转向架部件常用载荷形式有集中载荷、分布载荷、惯性力载荷。  

# 9.1.2.1集中载荷  

多用于描述构架受制动载荷、减振器载荷等。  

# 9.1.2.2分布载荷  

多用于描述摇枕、侧架、副构架、轴箱等受到的垂向、横向载荷，承载面面积相对较大，一般为均匀分布载荷。  

# 9.1.2.3惯性力载荷  

12  

多用于描述在加速度作用下与质量相关的载荷。如自重、冲击工况、悬吊部件载荷等。  

# 9.2约束  

# 9.2.1一般原则  

根据转向架各部件结构的实际受载情况，确定约束的施加方式。约束应保证求解时模型稳定、模型不因缺少约束而产生刚性位移。  

转向架部件常用约束包括支撑面区域约束、对称约束、接触约束、自由度耦合、强制位移约束等。  

# 9.2.2摇枕约束  

二分之一模型：摇枕弹簧单元约束垂向（Z向）位移，端部侧面多点约束中心节点约束纵向（X向)位移及绕丫轴转动，中央对称面施加对称约束。  

全模型：摇枕一端弹簧单元约束垂向（Z向）位移，端部侧面多点约束中心节点约束纵向（X向)位移、横向（Y向）位移及绕Y轴转动；另一端弹簧单元约束垂向（Z向）位移，端部侧面多点约束中心节点约束纵向（X向）位移及绕Y轴转动。  

# 9.2.3侧架约束  

二分之一模型：侧架端部垂向支撑多点约束中心节点约束垂向（Z向）位移和绕×轴转动，横向接触面多点约束中心节点约束横向（Y向）位移，中央对称面施加对称约束。  

全模型：侧架一端端部垂向支撑多点约束中心节点约束垂向（Z向）位移、纵向（X向）位移和绕X 轴转动，横向接触面多点约束中心节点约束横向（Y向）位移；另一端端部垂向支撑多点约束中心节点约束垂向（乙向）位移和绕X轴转动，横向接触面多点约束中心节点约束横向（Y向）位移。  

# 9.2.4副构架约束  

副构架轮对轮轨接触处约束垂向（乙向）位移和纵向（X向）位移，轮对中央断面约束横向（Y向）位移。  

# 9.2.5制动梁约束  

制动梁闸瓦托与闸瓦接触面约束纵向（X向）位移，制动梁端头一端约束横向（Y向）和垂向（Z向）位移，另一端约束垂向（乙向）位移。  

# 9.2.6弹簧托板约束  

a）最大横向载荷和疲劳载荷工况摇动座底部约束垂向（Z向）和横向（Y向）位移;b）扭转载荷工况弹簧托板另一端摇动座固定约束;c）菱变载荷工况弹簧托板加载端摇动座约束垂向（Z向）和横向（Y向）位移，另一端摇动座固定约束。  

# 9.2.7摇动座约束  

支撑座底部固定约束，中央对称面施加对称约束。

# 9.2.8构架约束

# 9.2.9轴箱约束  

模拟轴箱实际受力状态，与轴箱导框接触立面约束纵向（X向）位移、车轴中心位置约束轴箱垂向（Z向）位移，轴箱导框挡边约束横向（Y向）位移。  

# 10 工况组合  

铁路货车转向架主要部件静力学仿真考核工况应按照国内外标准及用户需求确定，分析时根据转向架受力情况考虑主要载荷和悬吊部件特殊载荷的可能组合。常用标准对转向架主要部件的考核工况见附录B和附录C。  

# 11模型检查  

有限元模型建立后，应进行模型检查。模型检查的内容应包括：  

a）模型单位制是否合理、统一；  
b）模型简化、等效是否合理;  
c）单元节点重复性、连续性、网格质量是否符合要求;  
d）各项材料、模型质量属性参数是否正确;  
e）检查载荷大小、约束位置、载荷工况、求解设置等是否合理;  
f）检查模型的收敛性、位移变形趋势、应力集中位置是否合理。  
g）检查模型约束反力值、接触力值，并与理论反力值进行比较，确定计算结果是否合理。  

# 12 分析类型  

# 12.1刚度分析  

在静载荷作用下，评估转向架主要部件结构抵抗变形的能力。  

# 12.2静强度分析  

车体结构在静态载荷作用下的响应，如应力、位移等，评估其抵抗破坏的能力。  

# 12.3疲劳强度分析  

车体结构在交变载荷作用下的响应，评估其抵抗疲劳失效的能力。。  

# 13 结果评估  

常用标准对转向架主要部件的考核工况见附录B和附录C。  

# 13.1刚度评估  

铁路货车转向架部件中摇枕、侧梁、制动梁的最大变形不应大于附录B中相关标准刚度工况下的许用值。其他部件刚度不作具体数值规定。

# 13.2静强度评估  

铁路货车转向架各部件在各工况下（含单工况）的应力不应大于附录B中相关标准规定的许用值。在超常载荷工况作用下产生的永久变形不大于附录B中相关标准规定的许用值。  

# 13.3疲劳强度评估  

疲劳评估参照相关标准规定的载荷值进行寿命评估，在标准规定的疲劳载荷总循环次数下，损伤累加和小于1或者应力幅小于疲劳极限图给定应力限度值。  

# 14 报告编制  

# 14.1报告内容  

仿真报告宜包括任务概述、计算对象、计算模型、载荷工况、评估准则、仿真结果、结论和建议等内容。  

# 14.2编写要求  

任务概述包括计算产品对象的来源，背景，分析类型、参考标准、分析软件、拟关注的分析结果等。  

计算对象包括结构简介，如主要结构和材质等。  

计算模型包括模型简化、网格划分、各类型单元和节点总数等。  

载荷工况包括载荷计算参数、载荷及约束情况、考核工况等，可配以图例。  

评估准则包括评估方法及应满足的相关评估指标等。  

仿真结果包括产品所涉及分析类型的计算结果。刚度仿真结果包括变形结果；静强度仿真结果包括应力结果汇总表、各工况下总体及局部高应力区的应力云图；疲劳强度仿真结果包括疲劳热点位置示意图、各工况下疲劳热点的损伤或者疲劳应力计算结果。  

结论包括对仿真结果的总体评判以及是否满足相关标准和设计的要求。
