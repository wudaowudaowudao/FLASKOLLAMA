# 2.2 新建视图

a）组合视图：easy3Ddrawing 软件该功能默认有6个视图可定义，除主视图外，其余视图设计师可根据需要选择。主视图选定后，单击其他视图，模型即会自动切换至相应视图面，设计选择曲面即可。如图2。  
b）与屏幕平齐：功能：定义模型技术要求等文字标注不随模型旋转的视图。应用于：技术要求、焊接说明、焊接表、其他文字说明等。  
c）单个视图：功能：辅助组合视图。应用于：剖视图等。

# 2.3 管理视图  

管理视图可实现如下功能：  

a）激活视图：选择某个视图（即注释特征），双击或右键选择【激活】。被选为当前视图之后，新的标注项目将在该视图上创建。如图3.  
b) 编辑视图：选择某个视图（即注释特征），右键选择【重定义】，在弹出的对话框中可重新定义视图的参考平面。  
c) 重命名视图：对视图名称进行重定义。  
d）移除视图：删除视图。

# 3视图创建要求  

# 3.1 组合视图  

组合视图创建应符合以下要求：  

a) 首次标注的模型，选择“组合视图”功能进行视图创建。  
b) 主视图的选择：确定模型主视图的原则是尽量符合零件的主要加工位置和工作位置;  
c) 主视图的投射：应选择最能显示零件各组成部分的结构形状和相对位置的那个方向。  
d） 通常模型应该有至少3个基本视图，并根据零件结构的特点，增加其他视图、剖视图等。如图6，定义支架的主视图、俯视图和左视图，即可完全表达零件的结构形状。

# 3.2 与屏幕平齐  

建立模型旋转过程中始终正对屏幕前方的文字注释、技术要求时需创建与屏幕平齐视图。  

# 3.3 视图命名规则  

创建组合视图后，系统会根据视图方向自动命名；  

当需补充单个视图时，根据视图方向按照主视图、后视图、俯视图、仰视图、左视图、右视图，如果单个方向需标注的尺寸较多需要分成两个层标注时可创建视图名称 $^+$ 序号，俯视图2。  

技术要求等建立与屏幕平齐视图，建立后改名为“技术要求”。
