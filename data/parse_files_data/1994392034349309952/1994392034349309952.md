# 4通用要求  

# 4.1 初始模板  

使用Teamcenter中标准模板。  

# 4.2草图设计  

4.2.1草图应完全约束，禁止草图出现约束不充分或过约束的情况。  
4.2.2草图不能与其它零件有直接的链接关系，避免其它零件变动导致不可预知的草图变化。  

# 4.3材料的选用  

4.3.1除不能确定材料的零部件（如供应商供货物料），三维模型中均应添加材料信息。

# 4.4零部件的命名  

4.4.1零件的命名应能表示物料的主要特征，同一类零件在同一系统内名称应尽量保持一致。示例：U形折弯板、L形折弯板、平板  

4.4.2对于生产过程中可能发生混淆或错用的零部件，命名时应体现其在车辆中的位置信息。示例：Tc车一位侧车顶边梁、Mp车一位端端墙对于可能同时应用于多个位置的零部件，可不体现位置信息。  

4.4.3系列件的命名应体现物料主要特征和变量规格。

4.4.4文件的命名  

零件和图纸的命名统一采用“编号_版本”方式，如PM081M1-211-000002_1。  
BOM的命名统一采用“编号_版本_BM”方式，如PM081M1-210-000000_1_BM。  

# 4.5零件的借用  

借用零部件需在BOM版本栏明确借用图纸的版本。  
本项目的不同车种之间不属于借用。  

# 5 三维设计  

# 5.1 零件设计  

5.1.1三维设计采用自顶向下设计方法，各系统在方案设计阶段应建立各级基准。总体设计师建立1级基准，系统设计师建立2级基准，部件设计师建立3级基准。基准建立后，应对相关基准点、线、面和草图等元素进行“发布”操作。相同基准元素，下级基准应引用上级基准中“发布”的，不应重复创建。  

5.1.2非供应商零件三维模型中必须添加材料信息，材料需从部门材料库中选取。供应商提供的三维允许采用材料库外的材料，但总重量应与部件理论重量一致。  

5.1.3零件三维完成后，应隐藏辅助设计所用的曲线、点、基准面等元素。  

5.1.4零件设计时，尽量不要从草图原点开始画线，避免无法移动情况。  

5.1.5草图完成后应使用“草图分析”命令进行草图检查。  

5.1.6三维设计时，不使用系统所定义的颜色，避免发生错误时难以发现。

# 5.4布线设计  

5.4.1CATIA完整的电气布线设计应遵循以下设计流程：  

机械3D环境下设置电气装置物理形状，并且在电气设计中给与电气特性和相关的物理配线(建立电气库)——从电气库中调用吸盘，扎带等电缆及线束固定件放置在合适的布线路径上——进行相关的电缆分布(电气布线安装)——根据需要从电气库中调用并放置线缆保护件)——根据实际需要对3D产品线束铺设(电线铺设)和展平(电气线束展平)。  

5.4.2若发生同一设备或连接器包含了多个电压等级的电缆，将此部件放置在电压等级最高的一层。  

1.4.3所有的线束的起始点及终止点都应定义BCP(Bundle Connection Point)点。  

5.4.4在三维布线应通过规定各种电压等级的线束颜色，用于明确和区分不同电压等级。  

5.4.5 电缆铺设时不得发生干涉与明显交叉。  

5.4.65A/5B/5C 等级需单独绘制每一根电缆。4 等级/2 等级/1等级电缆若无特殊要求，应按照需求分成几个线束绘制。  

5.4.7特殊定制电缆、光钎电缆等有特殊要求的电缆需单独绘制，并严格按照电缆要求铺设。  

5.4.8不同电压等级电缆或线束应该单独绘制。  

5.4.9不同电压等级电缆或线束同时连接到同一个电气元件应单独绘出每一个等级电缆或线束。  

5.4.10安装于存在相对运动的两个部件的电缆应按照动态弯曲半径绘制，并按照相对运动量合理设置松弛度。  

5.4.11电线、电缆的弯曲半径应符合TB/T1484.1-2010,第5.1条的规定：当电缆直径（D）小于或等于 $20\mathrm{{mm}}$ 时，最小弯曲半径不应大于4D（屏蔽电缆的最小弯曲半径不应大于6D)；当电缆直径（D）大于 $20\mathrm{mm}$ 时，最小弯曲半径不应大于6D（屏蔽电缆的最小弯曲半径不应大于8D)。  

5.4.12应符合TB/T 3153-2007第5.7条的规定：固定安装的电缆或使用时弯曲的电缆，其敷设时的最小弯曲半径不应小于相关产品资料或电缆标准中所规定的值。

# 6 工程图设计  

# 6.1 通用要求  

6.1.1工程图应与三维模型始终保持正确的链接关系。

# 7.2左、右件的编写规定  

7.2.1左、右对称的零、部件，结构较为复杂的应按左、右件分别绘制图样及编制图样代号；能清楚表达左、右件结构的简单零、部件，允许只绘制一张图样（图样的复杂程度由设计人员自行掌握），且一律以“左件”按规定绘制图样和编制图样代号，但是左、右件各给一个物料编码。  

7.2.2凡是分左、右件绘制的图样，其零、部件名称相同，只是在左件的名称后加“左”，右件的名称后加“右”，以示区别。  

7.2.3对于左、右件只绘制一张图样时，应在标题栏上部加“注：本图分左、右件，图示为左件。”BOM 表中左右件均列入，图号相同，物料号不同，右件在备注栏中写明“未出图”。  

# 7.3 “注”的书写规定  

7.3.1“注”的顺号用带圆圈的阿拉伯数字 $\textcircled{1}$ 、 $\textcircled{2}$ 、 $\textcircled{3}$ ……表示，圆圈采用细实线画，直径为 $\Phi5\mathrm{mm}$ o  

7.3.2“注”后的冒号“：”占一个字位，圆圈与空格占两个字位。注的条文第一条与注字同行，条文一行未完换行文字取齐，条文完了用句号“。”。“注”的条文中包括若干款、项时，其各项的顺号采用小写拉丁字母a、b、c等，此项顺号后移半个字位，拉丁字母后的间隔占半个字位。  

$$
\begin{array}{c}{{\textcircled{1}\times\times\times\times\times\times\times\times\times\times\times\times\times\times\times}}\\ {{\times\times\times\times\times\times}}\\ {{\mathrm{a.}\times\times\times\times\times\times\times\times\times\times\times\times\times}}\\ {{\times\times\times\times\circ}}\\ {{\mathrm{b.}\times\times\times\times\times\times\cdots\times}}\end{array}
$$  

7.3.3 “注”只有一条时也应写顺号 $\textcircled{1}$ 。

9.4.4（明细表） $\left.\rightarrow\mathrm{BOM}\right|\rightarrow$ 有关设计文件 $\rightarrow$ 一级装配图 $\rightarrow$ 直属零件及其借用零件 $\rightarrow$ 二级装配图（或借用部件，下同）及其直属零件和该装配的借用零件 $\rightarrow$ 三级装配图及其直属零件和该装配的借用零件 $\rightarrow$ 四、五·级装配等，直至编写完毕。  

# 9.5编写注意事项  

9.5.1无图件、紧固件、行业标准件等不编写在目录内。  
9.5.2本车借用件不编写在目录内。  
9.5.3历次设计的借用件应编写在目录内，但不计入张数。  
9.5.4各装配同时借用某一零件时，在图样目录中只可出现一次，并编写在先借用的装配中。  
9.5.5借用件为装配时，应安装配图的次序编写图样目录。  
9.5.6填写幅面时，若是图样幅面为加长幅面时，则按规定加长幅面填写，参见GB/T14689。
