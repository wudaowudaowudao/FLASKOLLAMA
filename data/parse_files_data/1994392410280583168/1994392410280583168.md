# 铁路隧道防水材料 第1部分 防水板  

# 1范围  

TB/T 3360的本部分规定了铁路隧道防水板的分类与标记、技术要求、检验方法、检验规则及包装、合格证、运输与贮存。  

本部分适用于铁路隧道工程用防水板。

# 3分类与标记  

3.1分类  

3.1.1乙烯醋酸乙烯共聚物改性聚乙烯防水板（VA含量不小于 $5\%$ ），代号EVA。  

3.1.2乙烯醋酸乙烯、沥青共聚物改性聚乙烯防水板（VA含量不小于 $5\%.$ ，沥青可溶物含量不小于$5\%$ ），代号ECB。  

3.1.3聚乙烯防水板，代号PE。  

3.2标记  

3.2.1产品本体上应有永久性标记，标记内容包含:制造厂标志-分类代号，根据需要可增加标记内容。  

3.2.2产品独立包装应有产品标记，标记内容包含：标准号-分类代号-规格（长度 $\times$ 宽度 $\times$ 厚度)，根据需要可增加标记内容。  

# 3.2.3 标记示例：  

长度 $30\textbf{m}$ ,宽度 $2.0\textrm{m}$ ,厚度 $1.5~\mathrm{mm}$ 的乙烯醋酸乙烯共聚物改性聚乙烯防水板标记为：TB/T3 $\mathbf{360.1-EVA-30\m\times2.0\m\times1.5\mm}$ 。

# 5检验方法  

# 5.1 尺寸测定  

5.1.1长度、宽度用钢卷尺测量,精确到 $1\ \mathrm{mm}$ o  

2  

5.1.2防水板厚度用分度值为 $\mathbf{0.01\mm}$ 、压力为 $(22\pm5)\mathbf{kPa}$ 、接触面直径不小于 $6\ \mathrm{mm}$ 的厚度计测量,保持时间为 $\textbf{5s}$ 。  

在防水板端部 $100\ \mathrm{mm}$ 以内任选一个断面，沿样品宽度方向按 $250\ \mathbf{mm}$ 等间距测量厚度，始末两个测定点应距样品边缘不小于 $25\ \mathrm{mm}$ ,按公式(1)计算厚度极限偏差。  

$$
\Delta t=\frac{t_{\mathrm{min}}-t_{0}}{t_{0}}\times100
$$

$\Delta t^{\prime}$ ———厚度极限偏差，以百分数计 $(\%)$ .  
$\pmb{t_{0}}$ ——对应规格的标称厚度，单位为毫米 $\left(\mathbf{m}\mathbf{m}\right)$ ；  
$t_{\mathrm{min}}$ 实测最小厚度，单位为毫米！ $\left(\mathbf{m}\mathbf{m}\right)$ 。

# 6检验规则  

# 6.1检验分类  

产品检验分出厂检验和型式检验。  

6.2出厂检验

6.2.1以同品种、同规格的 $\textbf{5000}\mathrm{m}^{2}$ 防水板为一批,不满 $\textbf{5}000\textbf{m}^{2}$ 按一批计。在该批产品中随机抽取3卷进行尺寸偏差和外观检查，在上述检查合格的样品中再随机抽取试样，进行性能检验。  

6.2.2 检验项目包括防水板的规格尺寸、外观质量、拉伸性能、撕裂强度、低温弯折性、不透水性、刺破强度。  

# 6.3 型式检验  

6.3.1有下列情况之一时应进行型式检验：  

a) 新产品试制定型鉴定;  
b) 产品的结构、工艺、材料等有重大改变;  
c) 停产6个月后复产；  
d) 出厂检验结果与上次型式检验有较大差异。  

6.3.2型式检验项目为本部分规定的全部要求，人工候化每年进行一次，其余各项为每6个月进行一次检验。  

# 6.4 判定规则  

所有检验项目全部符合要求，则为合格品。若性能有一项指标不符合技术要求，应另取双倍试样进行该项复检，复检结果仍不合格，则该批产品为不合格品。  

# 7包装、合格证、运输与贮存  

# 7.1包装  

防水板应采用具有一定阻燃性能的材料包装。  

# 7.2合格证  

防水板每一独立包装应有合格证，并至少注明产品名称、产品标记、制造厂名、生产批号、生产日期等。  

# 7.3 运输与贮存  

7.3.1运输时,不应使产品受到损伤。  

7.3.2堆放时，应衬垫平坦的木板，离地 $20\ \mathrm{cm}$ 。不同类型、规格的产品应分别堆放。平放贮存堆放高度不应超过5层，立放应单层堆放。贮存时，应避免日晒雨淋，且隔离热源;不应与酸、碱、油类及有机溶剂等接触。
