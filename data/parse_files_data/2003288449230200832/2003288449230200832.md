# 1.3 产品的主要用途  

HTM50100 车铣加工中心是一种具有高转速、高精度、高刚性的复合加工机床，由于具有Y 轴和B轴功能，因此机床加工工艺范围广，采用的刀具种类和规格较多，不仅具有车床的全部功能，还能够进行铣、钻等加工，该车铣中心的显著特点是铣削加工叶片螺旋面、加工偏心零件、铣削斜面等，特别适用于军工、航空航天、汽车、石油、能源等加工制造行业的复杂零件的加工，零件经一次装卡可加工完成全部或大部分工序，大大提高了工作效率，保证零件的加工精度。  

# 1.4 机床的精度  

本机床的精度符合中华人民共和国机械行业标准JB/T10889.1-2008《卧式车铣复合加工中心第1部分：精度检验》和JB/T10889.2-2008《卧式车铣复合加工中心第2部分：技术条件》。  

# 1.5 机床的使用环境  

本机床适合在下述规定的实际环境和运行条件中使用。  

$\bullet$ 环境空气温度： $5^{\circ}\mathrm{C}\sim40^{\circ}\mathrm{C}$ 范围内;  
$\bullet$ 湿度：最高温度 $40^{\circ}\mathrm{C}$ ，相对湿度不超过 $50\%$ 范围内，且湿度变化的原则是不应引起冷凝$\bullet$ 海拔高度： $1000\mathrm{m}$ 以下。  
$\bullet$ 大气污染：没有过分的灰尘、酸气、腐蚀气体和盐分。$\bullet$ 辐射：避免阳光直射或热辐射机床而引起环境温度的变化。  
$\bullet$ 安装位置远离振动源和易燃、易爆物品。  

# 1.6 机床对环境的影响  

本机床空运转噪声声压级 $\leqslant83\mathrm{dB}$ （A)，采用全防护结构，无有害气体或液体排放。因此对环境无不良影响。  

# 2安全防护须知  

本机床在供货时带有一些安全设备以防止操作人员与设备受伤害或损坏。操作者在开机前还应弄懂机床各种标牌内容及下述规定再上机操作。  

本说明书中所列入的安全注意事项，按导致机床、人身事故的伤害程度，分为三个等级叙述。对危险性较高的安全注意事项，操作时应特别注意。  

危险表示对高度危险要警惕，如不遵守本标记的事项，易导致死亡。  

警售表示对中度危险要警惕，如不遵守本标记的事项，会对机床、人身造成重大损伤。  
注意表示对轻度危险要关注，如不遵守本标记的事项，会对机床及人身造成损伤。  

# 2.1 对上机操作、维修人员的要求  

$\bullet$ 使用本机床的操作人员应是经过培训的且具有操作本机床资格的人员。操作人员上机前，应仔细阅读本《使用说明书》，并完全理解使用说明书中的内容，具备操作使用本机床的能力后方可操作。$\bullet$ 维修人员应由有资格的或具备专业维修能力人员来承担，以免发生意外。  

# 2.2 基本操作要求  

# 危险  

$\bullet$ 在控制面板、电机、变压器、端子盒里有高压标记的零件及部件，均带有高压接线柱，是非常危险的。禁止没有电工资格（上岗证）者触及这些器件。  

$\bullet$ 为了安全而设置的罩壳、开关、门之类的设施，未经本公司许可，禁止拆卸，更换。  

不要用湿手去触摸开关，否则会造成短路，危及人身安全。  

# 警  

$\bullet$ 应当非常熟悉急停按钮开关的位置，以便在任何需要时，无须寻找就会按到它。  

$\bullet$ 在安放保险丝之前，一定要将机床断电。  

$\bullet$ 当电源部分出现故障时，应立即扳断主电路开关。  

$\bullet$ 如果一项任务需由两个以上的人员来完成，在操作的每一个步骤上都应当规定出协调的信号，必须在给出规定的信号并接受后才能进行下一步工作。  

$\bullet$ 为防止跌倒事故，要及时擦除洒落在地面上的油和水，经常保持干燥的地面和通道。  

$\bullet$ 禁止不带手套处理切削液，当人员不慎接触到润滑液、冷却液、制冷剂等液体时，需采用以下措施：  

当皮肤接触时：用酸性肥皂和大量清水清洗。  
当溅入眼晴时，用大量清水至少冲洗15分钟。  
当误食入口时，应立即去医院就诊。  

特殊人群防护装备：使用化学物质设施时，需用防毒面具。  

$\bullet$ 机床操作人员在上岗之前必须进行安全操作培训，直至能安全操作后，才可操作本机床。  
且必须是一人操作。  

$\bullet$ 禁止戴着手套操作机床。（处理刀具、工件及清除切屑、清扫机床时必须戴手套。)  

# 注意  

$\bullet$ 操作人员应佩戴安全眼镜，必须穿戴适合操作的服装、安全鞋及安全帽，禁止穿宽松外衣、佩戴戒指、手镯和手表等各种饰物。  
$\bullet$ 长发者必须将长发卷绕在防护帽内，避免被机器卷入。  
$\bullet$ 装卸准备时，必须戴皮手套之类的安全防护工具，但按动操作面板上的开关、键、按钮时，不得戴手套。  
$\bullet$ 如因喝酒、吃药、生病等原因而缺乏正常的判断思维能力者，禁止操作机床。  
$\bullet$ 使用推荐的液压油、润滑油、恒温冷却水和油脂或认可的等同性能的液压油、润滑油、恒温冷却水和油脂。  
$\bullet$ 要使用具有合适电流值的保险丝，停电时必须立即切断总电源开关。  
$\bullet$ 要防止NC 装置、操作盘、电气控制盘受到冲击，否则，会引起故障使机床不能正常工作。$\bullet$ 不要随意改变参数、数值或其他电气装置。必须改变时，应该在改变前将原始数据记录下来，以便在需要时恢复到原始数据。  
$\bullet$ 不要弄脏、刮伤、弄掉或移动警告标牌。如果标牌上的字迹已变得模糊不清或遗失了，应向厂方订购新的标牌。  
$\bullet$ 要有足够的工作空间，以避免产生危险。  
$\bullet$ 水或油能使地面打滑造成危险，为防止出现意外事故，工作地面应保持洁净干燥。$\bullet$ 接近机床的工作台应结实牢固,以防止事故发生。要避免物件从工作台上滑下。  
$\bullet$ 在操作开关之前，一定要确认，不要弄错。  
$\bullet$ 不要随意触及开关。  

2.3 接通电源之前的要求  

# 危险  

电缆、线圈、电线如有损坏，会产生漏电，引发触电事故。因此，使用之前应进行检查。  

# 警  

一定要弄懂说明书和编程手册中所规定的内容。对每一个功能和操作过程都要弄清楚。$\bullet$ 应穿防油的绝缘鞋、工作服和配带其它安全防护设施。$\bullet$ 将所有NC装置、操作盘及电气控制盘的门和盖都关上。  

# 注意  

从工厂送电开关到机床总电源开关之间的电缆线要有足够的横截面以满足电力的要求。$\bullet$ 露在地面上的电缆必须有防护设施，以防止出现短路。$\bullet$ 机床拆箱后第一次使用或在长期停机后再启动之前，每个滑动部件必须重新上油。应使润滑泵连续工作，直到油从刮屑板处渗出为止。$\bullet$ 应将油箱的油灌到油标处，必要时需进行检查并注油。$\bullet$ 应将恒温冷却箱的冷却水灌到水标处，必要时需进行检查并注入规定的冷却水。$\bullet$ 有关润滑点、油的种类及油量，冷却水的种类及水量，请参见各自有关的说明标牌。$\bullet$ 各个开关及操作手柄应当灵活，平滑好用，应检查其动作。$\bullet$ \*当给机床送电时，依次接通工厂送电开关、机床总电源开关及操作板上的电源开关（置到“ON"位置）。$\bullet$ 检查冷却液的液量，必要时添加冷却液。  

# 2.4 接通电源之后的要求  

当操作板上的电源开关置于“ON”（接通）位置时（按上述中\*项要求进行接通）应检查READY（准备）灯是否亮。  

# 2.5 常规检查  

# 警告  

在检查皮带的松紧度时，千万不要将手指伸到皮带和皮带轮之间。  

# 注意]  

应检查压力表上反映的读数是否正确。$\bullet$ 检查电机、B轴等其它部件，确保没有不正常的噪声。$\bullet$ 检查机床各部分的润滑情况。$\bullet$ 检查防护罩及安全保护装置是否处于正常工作状态。$\bullet$ 检查供气的气源是否达到使用要求。  

2.6 温升  

# 注意  

$\bullet$ 给机床升温，尤其是给主轴和进给轴进行升温，应该在机床的自动操作状态下，以最大速度的一半或三分之一使机床运转 $10{\sim}20$ 分钟，达到稳定温升。  
$\bullet$ 在自动操作时，机床上每个运动部件都要按程序自动运作，与此同时，检查各个运动部件的运作情况。  
$\bullet$ 如果机床闲置了很长时间，不要一开车就进行加工，一定要对机床采取升温。这是因为机床长期闲置后油润滑不充分，很可能使滑动部件受到磨损，导致机床部件热膨胀，影响加工精度。  

2.7 开机前的准备工作  

# 警告  

工装应确保符合机床的技术参数、尺寸和型号。  

$\bullet$ 刀具磨损过度或损坏，直接影响工件加工或损坏机床，因此开机前应将这些刀具换下。  

$\bullet$ 加工区要有良好的照明，以便于安全检测。  

$\bullet$ 机床或设备周围的工具及其它物品应存放有序，保持环境整洁及通道畅通。  

$\bullet$ 工具或其它任何物品都不要摆放在主轴箱、铣头、盖或类似的位置上。  

$\bullet$ 如果重型的圆柱件中心孔太小，加载后，工件很可能会跳出顶尖。所以，一定要注意中心孔规格及角度。  

# 注意  

工件长度应在限定的范围内，以防止发生干涉。$\bullet$ 刀具安装后，应进行试运转。

# 3.3 如何安装  

对于机床来说，安装的方法对机床的功能有极大的影响。如果一台机床的导轨是精密加工的，而该机床安装不好，则使其不能达到原始精度。这样，就很难获得所需要的加工精度，大多数故障  

都是因安装不当而引起的。  

必须仔细的阅读安装步骤，并按照规定的安装要求来安装机床，这样才能使机床进行高精度的加工。  

# 3.3.1 安装  

# 3.3.1.1地基  

安装机床应首先选择一块平整的地方，然后根据第3.1节的规定安装环境进行安装，根据地基图决定安装空间。  

占地面积包括机床主机本身的占地和附属设备占地。此要求已在地基图中作了规定。  

# 3.3.1.2临时水平调整  

1）吊起机床，将地脚螺钉放入调水平地脚垫铁孔中。2）然后将机床慢慢地放下，让地脚螺栓按地基图的规定穿过调整垫铁并进入床身底部的地脚螺栓孔中。3) 从吊杠中取出吊绳。4) 将楔铁打入床身的下面进行临时性水平调整，做到粗调平。5) 完成调整后，用水泥将地脚螺栓固定。  

# 3.4 内部装置连接的检查  

完成调水平工作后，开机前要检查下列各项：  

$\bullet$ 确保地线连接无误。  
$\bullet$ 拧紧终端连接的螺钉。  
$\bullet$ 重新检查各连接器是否接紧。  
$\bullet$ 确保继电器和计时器连接正确。  
$\bullet$ 确保计时器和其它仪表所设定的数值准确无误。  
$\bullet$ 确保NC 装置中的印刷线路板牢固无松动。  
$\bullet$ 检查并确保输入电源相序正确。  

# 3.5 操作前的检查  

完成内部装置连接后，应按以下规定对机床的机械系统和电气系统加以检查。

有无遗失零件或附件  
润滑油、液压油、冷却水、冷却液是否已供到机床各个部位  
液压管路和气动管路是否全部接好  
供气气源是否满足本机床的使用要求  

接通电气前后的电气系统检查：参看第2部分安全须知。  

$\bullet$ 机床处于长期停机状态下的注意事项：机床安装后或机床长期停机后重新开动机床时，应先手动启动润滑泵若干次，使滑动表面有充分润滑油。  

$\bullet$ 安装、运输、包装卸下的零件。机床安装以后，应将那些用于吊运机床的板、螺栓及其它物品卸下后保存好。■ 应将那些为了包装而卸下的并分开包装的附件安装到原来位置上。  

清洁

# 3.7 安装后的维护及内部装置连接的检查  

为了长期地保持机床的精度及保证机床处于正常的良好工作状态，必须对机床给予适当的维护。认真地观察机床的工作状态，定期检查和及时地更换磨损件能够防止机床产生意外的故障。  

# 3.7.1 安装最初阶段的维护  

机床安装后的最初阶段，由于地基地面的变化和地基不稳定的固化等因素，床身水平会有明显的变化。这会严重地影响机床精度。另一方面，由于最初的磨损等原因，机床极易受到污染，诱发机床故障。为了长期地保持机床的精度及保证机床处于正常的良好工作状态，必须对机床给予适当的维护。认真地观察机床的工作状态，定期检查和及早地更换磨损件能够防止机床产生意外的故障。  

机床安装的最初阶段维护保养措施如下：  

$\bullet$ 试车  

机床安装完成后，一定要非常谨慎地试车。试车时间约为80小时，在整个试运转期间不应使  

用大负荷试车。  

$\bullet$ 检查最初阶段床身水平情况  

安装后的6个月内，至少每个月检查一次床身水平和地基。如果发现不正常的现象，应及时调整以确保达到床身的水平精度要求。  

$\bullet$ 6个月后，可视情况变化适当地延长检查周期，待变化稳定到一定程度，一年可进行一次或二次的定期检查。  

# 3.7.2 检查内部装置的连接情况  

检查NC装置、主机、液压装置、控制板及其它装置，确保它们的电气连接正确。  

$\bullet$ 连接器有无松动  
各装置间的相互电气连接是否正确，检查每个连接点是否出现松动，若有松动应拧紧。$\bullet$ 接线端螺钉是否松动  
检查机床接口和控制板上的电气设备的接线端的螺钉，如有松动，将其拧紧。  
$\bullet$ 检查微型开关上的接线端子的螺钉和安装螺钉有无松动，如有将其拧紧。  

# 3.7.3 检查电气控制板  

检查电气控制板之前，一定要先关闭机床的电源。然后对各部加以检查。  

$\bullet$ 接线端螺钉和焊接件  

检查每一个电气设备上的端子螺钉，如有松动应拧紧，对继电器板上的焊接件应用手轻轻地拉动以确认其是否焊牢。  

$\bullet$ 消弧器  

检查每个消弧器，如有变色，应及时更换。  

$\bullet$ 清理  

如果电气控制板内有灰尘、切屑、脏物或相类似的杂物会引发故障，应细心地清除。  

$\bullet$ 如果空气过滤网变黑，说明已受污染。应该拆下用水轻轻地加以清洗。

# 5.3.3 卡盘  

卡盘安装在主轴前端面的法兰盘上（见图13)，旋转油缸装于主轴的后端，两者通过拉杆连接起来。当旋转油缸中的活塞向前移动时，卡爪通过卡盘内部的楔形柱塞结构张开，活塞缩回时，卡爪收缩。旋转油缸由缸体、旋转组件、连接板等组成，油缸还装有“安全锁机构”能够在压力源出现问题而造成供油压力失常的情况下，维持油缸内部的固定压力。  

卡爪的结构形式必须与所卡的工件形状相适应，为了保证卡盘安全使用，保持其高精度及使用寿命，对卡盘及油缸的使用及维护都做了一些必要的规定及限制，因此，要仔细阅读卡盘及油缸的操作、维护手册，并按手册中所要求的去做。如果用户在生产过程中，需要购买卡盘的软、硬卡爪，可以根据卡盘的型号直接向卡盘生产厂家订货，也可以与我们联系，协助用户采购。

# 5.3.4.1返零原则  

在铣头移动范围内，有一个叫机床零点的参考位置。NC 装置确立的机床座标系，将这个机床零点作为参考点，用以控制刀具的位移。  

HTM50100车铣中心的三个直线进给轴的伺服电机和各个旋转进给轴均采用绝对编码器形式，调好机床三个直线进给方向的零点后，NC装置能够保存该零点位置，所以接通NC 装置电源后，不必进行“零点返回操作”  

如果因为某种原因引起机床零点位置变化，则应将零点重新调整到正确位置。  

# 5.3.4.2刀具设定  

操作者编程时，可把机床零点作为参考点来进行。这种编程方式使用起来不太方便。操作者可根据G50设定工件座标系来进行编程，相关内容请参考系统操作手册。  

# 5.3.4.3Z轴偏置  

在实际编程中，将加工后工件的右端面设定为参考点，称之为“加工程序零点”。乙轴偏置是指参考程序零点和加工程序零点之间的距离，通过“Z座标偏置”将这个值输入到NC 装置中，工件座标系统的参考点就从参考程序零点移到了加工程序零点。

# 5.3.6 B轴系统  

HTM50100的B轴系统具有转位速度快、重复定位精度高、许用扭矩大等特点，大大加强了本机床的铣削的能力。B轴的功能是带动刀具主轴在 $\pm100^{\circ}$ 范围内摆动，B轴有以下三种工作状态：  

（1）带动刀具主轴每 $5^{\circ}$ 转位；  

首先定位锁紧油缸动作将锁紧齿盘脱开，转动B轴至 $5^{\circ}$ 的整数倍，刀具到达预定位置后B轴伺服电机停止，定位锁紧油缸动作将锁紧齿盘与定齿盘和动齿盘啮合，使刀具主轴精确定位并锁紧。  

（2）带动刀具主轴任意位置转位  

首先定位锁紧油缸动作将锁紧齿盘脱开啮合，转动B轴，刀具到达预定位置后B轴伺服电机停止，任意位置锁紧油缸动作将B轴锁紧，使刀具主轴在任意位置定位并锁紧。  

（3）带动刀具主轴做插补运动  

首先定位锁紧油缸动作将锁紧齿盘脱开啮合，任意位置锁紧油缸动作将B轴松开，B轴伺服电机带动铣头在 $\pm100^{\circ}$ 范围内摆动，实现插补加工。

# 5.3.9 气动系统  

使用说明：本机床采用FESTO进口气动元件。主要实现：  

1）刀具主轴气密封，防止冷却液及铁屑溅入刀具主轴前端，影响使用性能。  
2）刀具主轴锥孔清洁，防止换刀时刀具拉紧不可靠。  
3）传动部件伞齿轮处的油气润滑功能。  

4）刀库门、外防护气动门等移动。  

本机床的气动系统由空气组合元件开关阀 HE-D-MINI、过滤减压阀LFR-3/8-D-MINI-MPA、气路板VABM-L1-18S-G38-3等元件组成，通过两位电磁方向阀VUVG-L18-P53C-T-G14-1P3、VUVG-L18-T32C-AT-G14-1P3等组成。

# 6机床的使用和安全防护  

# 6.1 机床的使用  

机床的启动及运行过程中的操作程序、停机操作程序、操作方法和注意事项及容易出现的错误操作和防范措施见本机床《电气使用说明书》。  

# 6.2 安全防护  

$\blacktriangle$ 全封闭防护  
本机床具有全封闭防护罩防护，并考虑多项安全保护措施。  
乙轴采用多层拉式防护罩，采用左右布置式设计，使排屑方便及冷却液易于收集。  

$\blacktriangle$ X轴、Y轴、乙轴设有软超程保护。由于某种原因(操作失误、编程数据错误、伺服故障等)使铣头在某一方向的移动超出了限定的范围，数控系统会立即进入急停状态，发出报警并停止铣头的移动。  

$\blacktriangle$ 冷却泵安装在排屑器水箱上，具有多层过滤，使冷却液得到了充分的净化，避免冷却回路堵塞。  

$\blacktriangle$ 机床电气设计符合GB5226.1电气标准。电路的动力回路，均有过流、短路保护，机床相关动作都有相应的互锁，以保障设备和人身安全。  

$\blacktriangle$ 电气系统具有自诊断功能，操作及维修人员可根据指示灯及显示器等随时观察到机床各部分的运行状态。  

$\blacktriangle$ 电气柜  

电气柜标准配置采用全封闭式，用空调器散热，并在电气柜内预留一定空间以便于扩展功能。  

意外断电或发生故障时的保护  

当机床遇到外部突然断电或自身故障时，由于控制电路的特殊设计，机床可动进给轴，冷却电机等如已在“启动”状态者，将进入“停止”状态；如已在“停止”状态的则不可自行进入启动状态，确保了机床的安全。另外由于机床计算机内的控制程序是“固化”在芯片中的，而零件加工程序是由电池供电保护的，所以，意外断电或故障时，不会丢失计算机内存储的程序菜单。  

$\blacktriangle$ 机床具有报警装置及紧急停止按钮，可防止各种突发故障给机床造成损坏。由于软件的合理设计，报警可通过显示器显示文字及报警号，通过操作面板的指示灯指示；机床根据情况将报警的处理方式分为三类：对紧急报警实行“急停”；对一般报警实行“进给保持”；对操作错误只进行“提示”。  

# 6.3 设置必要的安全警告标牌  

本机床尽管采取了诸多安全防护措施，但仍存在一些潜在的、不明显的危险，为提示操作者，本机床设置了必要的安全警告标牌。安全警告标牌有：安全说明标牌、防护门警告标牌、主轴警告标牌以及当心触电标牌等。

# 7.4.3.1返回零点操作  

在铣头运动范围内，有一个叫“机床零点”的参考位置。NC 装置建立的座标系，就把这个机床零点做为参考点，用以对铣头的定位进行控制。该车铣中心的三个直线进给轴的AC 伺服电机均采用绝对编码器形式，调好机床三个直线进给方向的零点后，NC 装置能够保存该零点位置，所以接通NC装置电源后，不必进行“零点返回操作”。该车铣中心的B轴和C轴也都采用绝对式编码器形式，不必进行“零点返回操作”。  

除非编码器输入轴与滚珠丝杠的相关位置发生变化，否则，机床的零点位置设定好后就永远不会变化。  

# 7.4.3.2机床零点的重新设定  

当编码器输入轴与滚珠丝杠之间的相关位置发生变化时，例如，当弹性连轴节被重新调整后或机械挡块因某种原因移动时，机床零点将不在原来的位置上，这种情况下，要按以下步骤重新确定机床零点。

# 7.4.4 间隙  

安装在X轴、Y轴、乙轴上的编码器与铣头之间因存在着如下的误差环节，诸如：丝杠与螺母之间的间隙，丝杠弯曲及某些部位的弹性变形等等，使NC 装置发出的指令值与铣头实际移动值之间产生误差。  

# 7.4.4.1间隙的补偿  

如果间隙太小，轴承等类零件上就会出现过载，从而会缩短这些零件的使用寿命。此外，过小的间隙也是机床工作期间产生噪声及爬行，直接影响加工质量的原因。因此，要考虑适当加大其间隙问题。为了补偿由于上述驱动系统而产生的误差，本机床的数控装置中配置了间隙补偿器。  

机床出厂前，间隙补偿量已定在最佳位置上，但机床长期工作后这个补偿量也会变得不适宜。因此，要重新设定这个量。可以通过改变寄存在NC 装置内的参数来重新设定间隙补偿量。

# 7.4.6机床的其它维修  

$\bullet$ 床身水平检查  

机床安装后的前六个月每月检查一次床身的水平情况。如水平超差，就应调到正常值。六个月后，可根据需要不定期进行检查，如果客观条件没有多大变化，一年检查一至二次即可。  

$\bullet$ 刮屑器的检查  

安装在每个滑动部位上的刮屑器用以防止切屑进入导轨内并保证润滑油均匀润滑。请注意：切屑和类似的东西会引起刮屑器边缘破损，所以，一旦发现刮屑器破损应立即更换。  

$\bullet$ 密封涂层  

机床在出厂前，切削区都是密封的以防止漏水。如发现漏水，应该使用标准工具涂密封胶。

# 7.4.7.1电气元件检查  

定期检查电气元件及控制器。  

# 7.4.7.2X轴、Y轴、 $\mathbf{z}$ 轴、B轴和刀库伺服电机检查  

定期进行检查和维修。  

# 7.4.7.3机床各部分电气连接的检查  

检查NC 装置，机床主机，液压装置、控制箱等各部分电气连接有无松动。  
$\bullet$ 连接器  
检查各连接器的连接有无松动，如有，应重新拧紧。  
$\bullet$ 接线端子的螺钉  
检查继电器和每个操作板上各电气件接线端子螺钉是否松动，如有松动，请重新拧紧。  

# 7.4.7.4控制箱的检查  

检查控制箱时，应切断电源  
$\bullet$ 接线端子螺钉及焊点  
检查电气件接线螺钉，如有松动重新拧紧，轻轻拉动继电器板上的焊接部分，检查是否焊牢。$\bullet$ 空气开关  
检查空气开关是否失效。  
$\bullet$ 消孤器  
检查消孤器，更换变色的消孤器。  
$\bullet$ 清理

$\bullet$ 空气过滤网  
用水轻轻地清洗空气过滤网上的灰尘和污物。  

# 7.5 常见故障排除  

# 7.5.1 常见故障及产生原因  

# 7.5.1.1冷却液不能流出  

$\bullet$ 操作板上冷却液开关设定是否正常。M指令代码是否有误。  
$\bullet$ 冷却泵吸入口是否完全插入冷却液中。  
$\bullet$ 切屑盘过滤网、过滤器和泵吸入过滤器有无堵塞。  
$\bullet$ 冷却泵电机是否工作。  
$\bullet$ 在控制板上，冷却泵电机热继电器接线是否脱落。  

# 7.5.1.2主轴箱异常温升  

$\bullet$ 主轴箱负载过大或机械元件损坏。  
$\bullet$ 主轴轴承预紧力设置不适当。  

# 7.5.1.3X轴、Y轴和Z轴零点消失  

$\bullet$ NC装置供电电池没电。  

# 7.5.1.4重复定位精度不好  

$\bullet$ 导轨润滑不适当。  
$\bullet$ 联轴器螺钉及涨紧套螺钉松动。  

# 7.5.1.5卡盘的卡爪不工作  

$\bullet$ 调整卡紧力的减压阀设定值不正确;  
$\bullet$ 卡爪张开/闭合电磁阀工作不正常;  
$\bullet$ 脚踏开关功能失常；  
$\bullet$ 与脚踏开关动作相关的继电器工作不正常;  

$\bullet$ 楔形块和卡爪没卡住。  

# 7.5.1.6液压卡爪行程小  

$\bullet$ 内部是否有大量的切屑;  
$\bullet$ 旋转油缸和连杆是否有松动。  

# 7.5.1.7精加工件出现形状误差  

$\bullet$ （加工盘类件时）  
主轴箱定心不适当（加工轴类件时）  
尾台顶尖定心不适当  
$\bullet$ 是否达到了良好的安装精度。  

# 7.5.1.8第二主轴箱或尾台不能正常移动  

$\bullet$ 锁紧油缸是否将第二主轴箱体(或尾台)锁紧在导轨上。  
$\bullet$ 第二主轴箱体(或尾台)移动部分的润滑不好，会使其卡住。  

# 7.5.1.9在X轴、Y轴、、Z轴移动时显示“伺服滞后过度”报警  

$\bullet$ 连轴器松动。  
$\bullet$ 直线导轨有卡住现象等。  
$\bullet$ 滑动面润滑不好（油路堵塞)。  

# 7.5.1.10 润滑系统  

润滑系统无油或某些润滑点无油  

$\bullet$ 油路报警是否工作正常。  
$\bullet$ 润滑油箱的油量太少。  
$\bullet$ 润滑点端部计量件失效，须换新的计量件。  

# 7.5.1.11气动系统  

$\bullet$ 气源压力是否符合工作要求。  
$\bullet$ 气动管路是否漏气。
