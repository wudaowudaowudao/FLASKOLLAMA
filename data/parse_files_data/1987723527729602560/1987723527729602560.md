# 基于Creo的三维标注规范第4部分：粗糙度注法  

# 1范围  

Q/YD 00-028的本部分对表面粗糙度的图形符号、参数代号及其在模型上的注法给出了规范性要求。  
本规范适用于公司技术人员使用CreoParametric软件进行的产品设计开发。  

# 2规范性引用文件  

下列文件对于本文件的应用是必不可少的。凡是注日期的引用文件，仅注日期的版本适用于本文件。凡是不注日期的引用文件，其最新版本（包括所有的修改单）适用于本文件。  

GB/T131-2006产品几何技术规范技术产品文件中表面结构的表示法GB/T3505产品几何技术规范(GPS）表面结构轮廓法术语、定义及表面结构参数  

# 3基本要求  

3.1三维标注中粗糙度的标注应与其他标注（如尺寸、几何公差、焊接等）协调统一，不允许存在任何重叠。  

3.2粗糙度的标注平面（记录标注符号所使用的截面）应尽可能的少，并应尽可能标注在同一标注平面内。  

# 4表面粗糙度的图形符号  

图形符号包括基本图形符号、扩展图形符号、完整图形符号和周边轮廓图形符号，均应符合GB/T131-2006的规定。  

# 5粗糙度参数  

粗糙度参数代号应符合GB/T3505的规定。  
粗糙度参数代号、数值在粗糙度完整图形符号中的标注位置和方向应符合GB/T131-2006中5.2条要求。
