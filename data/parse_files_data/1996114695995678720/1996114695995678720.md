# 重庆高速公路集团有限公司关于修订《招标限价管理办法》的通知  

集团各部门、中心、分公司，全资及控股子公司：  

为进一步完善集团招标限价管理制度，优化相关程序，集团对《招标限价管理办法（试行）》进行了修订，并经集团2021年第16次党委会前置研究和2021年第5次总经理办公会决策通过，现予印发，请遵照执行。原《招标限价管理办法（试行）》（渝高速文［2019］389）自办法印发之日起废止。

# 重庆高速公路集团有限公司招标限价管理办法  

# 第一章总则  

第一条为建立控制有力、制约有效、运转良好的招标工作机制，更好发挥招标限价的作用，合理确定和有效控制工程、物资和服务采购成本，根据《中华人民共和国招标投标法》《公路工程造价管理暂行办法》（交通运输部令2016年第67号）《重庆市公路工程造价管理实施细则》（渝交委路［2017］129号）等法律、行政法规以及有关主管部门的相关规定，结合集团《招标投标管理办法》《非必须招标物资采购管理办法》及实际情况，制定本办法。  

第二条对集团各部门、中心、分公司、全资子公司、控股子公司及实际控制子公司在建设、运营养护、投资、产业、后勤保障和社会服务等业务板块进行的招标限价管理，适用于本办法。  

第三条集团《招标投标管理办法》中明确的必须招标项目，实行限价先报审后备案制度。符合以下情形之一的项目实行限价告知性备案制度：  

（一）非必须招标项目。（二）通过市场化方式承接的工程、物资或服务，以及为实  

现其功能涉及到的招标项目。  

（三）企业经营商贸流通业务中的招标项目。  

第四条招标限价管理应当遵循客观科学、公平合理、诚实信用、厉行节约的原则，主动接受有关部门的依法监督。  

# 第二章 机构及职责  

第五条 招标限价管理服从集团招标领导小组的统一管理，招标领导小组主要负责制定限价管理制度、决定招标限价管理中的重大事项。  

第六条集团各部门按照职责分工负责招标限价的管理  

（一）风控法务部为集团招标限价管理的归口管理部门，在招标领导小组的领导下，负责统筹集团招标限价管理，负责组织必须招标项目限价审查工作，指导非必须招标项目限价管理工作。  

（二)集团各部门（中心）或各子分公司负责本部门（中心）或本单位招标限价管理工作，各子分公司应建立健全内部限价管理实施细则，并对招标限价价格水平控制及招标限价成果文件的准确性、完整性负主体责任。  

（三）建设管理部参与招标限价审查，负责对招标文件及限价发表专业意见。  

（四）集团各相关业务部门（中心）按类别参与相应招标项目限价审查，负责对招标文件及限价发表专业意见。  

（五）审计部负责对招标限价管理实施审计监督。  

（六)纪检监察部按照有关规定以及集团规章制度，负责查处招标活动中的违规违纪行为。  

# 第三章 招标限价编制  

第七条 招标项目应当设置限价，招标人具备编制能力的可自行编制，不具备编制能力的可委托具有相应造价资质的咨询单位进行编制。招标限价不得超过经批准的概算或者预算，招标人应当对所编制的限价的准确性和完整性负责。  

第八条 招标人应当结合市场行情、类似项目经验、项目具体情况、评标办法等因素合理编制限价文件，控制限价水平。计价依据包括但不限于：国家、行业相关办法、规则、定额、费用标准、造价指标及其它相关计价标准；集团内部定额及费用标准；近三年历史采购价格；市场调查；审批施工图预算下浮等。  

第九条招标人凡委托咨询单位编制限价的，应当按照集团招标管理有关规定选择具备相应资质的单位，咨询单位限价编审人员应当具备《造价工程师职业资格制度规定》（建人［2018］67号）规定的相应执业资格。  

第十条报审及内部归档招标限价成果文件须加盖招标人公章、编制单位公章及资质印章（若委托）满足执业要求的编制人资格印章并签字（见附表六）。  

# 第四章 必须招标项目限价管理  

第十一条 必须招标项目招标人在施工图设计及预算文件、招标文件审查通过（水利水电项目在初步设计及概算文件、招标文件审查通过)，并完成招标限价招标人内部审查程序后方能报送风控法务部组织招标限价审查。  

第十二条 招标人在招标限价报审时，应填写《招标限价审查登记表》（见附表一），同时将报审招标限价成果文件、经审查后施工图设计及预算文件（水利水电项目为初步设计及概算文件）、经审查后的招标文件等相关资料（见附表四）报送风控法务部，以上所涉及的书面资料均须加盖招标人公章。  

第十三条 风控法务部在确认报审材料的完整性后，结合项目规模，原则上在5-10个工作日内（见附表二）组织召开招标限价审查会，招标人（部门负责人及经办人员）、建设管理部及相关业务部门（中心）参加，并可根据项目情况外聘行业专家或引入造价咨询单位参加。  

第十四条风控法务部负责汇总限价审查意见，可根据市场行情及项目实际情况对限价作适当上浮或下浮调整，形成《招标限价审查备忘录》（见附表三）招标人应依据审查意见对限价文件进行修订完善，并按照招投标相关规定程序发布限价。招标人须在限价发布后5个工作日内将《招标限价备案表》（见附表四）限价修改说明及修订完善的招标限价成果文件等资料（见附表六）报风控法务部备案。  

第十五条招标项目流标后需重新招标的，招标人应分析招标失败的原因，如属于招标限价设置不合理需作调整的，应重新履行招标限价审查程序。  

第十六条参与限价编制、审查的人员应严格遵守保密纪律，在限价发布前不得向无关人员透露审查情况、结果和其他相关信息。  

# 第五章 非必须招标、市场化项目限价管理  

第十七条实行告知性备案制度的项目，招标人按内部限价管理实施细则自主确定限价，实施细则应明确非必须招标项目限价编制、审查、发布等相关流程，集团部门的可合并入非必须招标项目询价（比选）文件审批流程，审批内容体现出限价及限价编制依据。  

第十八条招标人须及时将非必须招标、市场化项目招标情况录入内部限价管理台账（见附表五)，并于每季度的首月5日前提交风控法务部备案。  

# 第六章 监督管理  

第十九条集团各部门和各单位应当加强招标限价档案管理，确立招标限价归口管理部门（集团部门确定归口人员)，应当将招标限价全过程资料及备案资料（见附表六)按照集团档案管理相关规定归档，并建立招标限价管理台账，于每季度的首月5日前将截止上季度末的限价台账（见附表五）及中标情况（见附表六)提交风控法务部备案，风控法务部定期将对各单位送审资料完整度及编制质量、备案进度及资料修改情况进行通报。  

第二十条风控法务部每半年对各部门和各单位招标限价的管理进行抽查，并形成半年检查报告。集团年度组织对各单位招标限价管理进行综合评价，招标限价管理水平纳入公司年度绩效考核评价；造价咨询单位服务质量参照集团《非必须招标项目合格供方库管理办法》进行履约评价，评价结果作为招标商务评审或入库的重要参考依据，服务成果有重大质量问题的（如多次出现定额不能正确理解、定额套用与设计图不符、定额套用不合理等)，经过相关程序可终止其合格供方库资格。  

# 第七章 附则  

第二十一条 本办法由风控法务部负责解释  

第二十二条本办法自印发之日起施行，《集团招标限价管理办法》（试行）（渝高速文［2019］389号）同时废止。施行过程中上级部门和集团有新要求的，以新要求为准；与国家法律法规冲突的，按照国家法律法规要求执行。
