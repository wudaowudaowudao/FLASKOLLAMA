# 铁路应用 机车车辆布线规则  

# 1范围  

本标准规定了铁道机车车辆(包括磁悬浮列车与无轨电车)以及安装在铁道机车车辆上的电气柜(箱)内部的电缆布线要求。  

本标准适用于在铁道机车车辆电气设备间及其电气柜(箱)内部完成各项产品(包括电缆、汇流排、端子与插头、插座)电气连接所进行的布线。  

注 本标准适用于无轨电车的整个电力牵引系统,包括受流回路、电力变流器以及它们各自的控制回路。其他回路的布线由公路车辆(如内燃机驱动的公共汽车)标准来规定。  

本标准规定的材料选取标准适用于含铜导体的电缆，但不适用于特定用途的导体，如光缆或空心导体(波导管)。  

本标准不适用于：  

一专用的机车车辆，如铺轨机、道碴清筛机和职工运输车；用于采矿的机车车辆；  
一有轨电车；缆车。  

由于机车车辆的布线也涉及到电缆的制造标准，所以应参考 TB/T 1484、GB12528.11、EN50264、EN50306与EN50355等标准。  

本标准应结合相关的产品与安装标准使用。也可以规定比本标准更严格的要求。  

城轨车辆、地铁车辆可参照本标准。

# 5技术要求  

# 51一般要求  

电缆与布线材料应经过型式试验，选取的截面积与安装应与它们在工作条件下的功能相适应。电缆(或汇流排)的截面积与布线应考虑预计在机车车辆上的特殊应力。所用材料与布线方法应能防止拉伸或摩擦。  

机车车辆电缆除用于输、变电、电能采集、电气控制或系统监控外,不能用作其他用途。布线的所有部件应经过选择、安装、保护、使用和维护以防止危害(如电气或火灾隐患,EMC问题)。  

电气连接在使用时,不能由于热效应、动态(如预期的冲击、振动、车体运动等)负载而被无意识地断开或中断。  

环境条件应按TB/T1333.1的规定。  

电缆布线的电气隐患防护应按TB/T3076的规定。

# 5.2 2 控制电缆截面积的选择  

仅用于控制信号传送的控制电缆，应具有5.5所规定的最小导体截面，也可以根据负载电流选择更小的导体截面。  

注控制电缆的导体截面积不要求按照523进行选择。  

# 5.23以负载电流为基础的配电电缆截面积的选择  

本条规定不同截面积电缆的最大持续负载电流的计算方法，它取决于电缆的敷设方式和环境温度，使所选电缆能达到预期寿命。  

在 EN50264和EN50306中各部分规定的各类电缆，其导体的最大持续温度为 $90\mathrm{\textperthousand}$ 或 $105\mathrm{\textperthousand}$ 0这些值是以多年来的实践经验和可靠性为依据得出的，或在新的、已规定的、通过验收试验的绝缘材料的条件下，使用长期耐热老化试验宋证实在 $110\mathrm{\textperthousand}$ 和 $125\mathrm{~\textperthousand~}$ （即比持续定额高 $20\thinspace\mathbb{C}$ )时的寿命至少为$20000\ensuremath{\mathrm{h}_{\mathfrak{c}}}$ 。注意,耐热试验中的数据能外推出在持续负载时，提供电缆预计寿命的导体温度。此预期寿命结合机车车辆的工作周期、预计的不使用时间一起，可用于估计电缆在整个机车车辆的预期寿命内，能够可靠运行的能力。

# 57 弯曲半径与其他机械要求

注1在EN50355中详述了机械应力。  

注2弯曲半径会影响屏蔽电缆的EMC效应。  

# 58 重新端接  

导体标称截面积小于或等于 $16~\mathrm{mm}^{2}$ 的单芯或多芯电缆敷设在机车车辆上时，在每一端应留有足够的备用长度以允许进行至少3次的重新端接。  

注当电缆用插头端接时，不应留有备用长度。  

# 59汇流排  

汇流排应由铜或铝制成。在接触表面上，应采取预防措施以免表面接触电阻增大,特别是由于腐蚀或爬电距离所引起的。  

汇流排应符合有关标准的规定。汇流排型号与尺寸的选择应由机车车辆制造商决定。分组选择时应考虑包括环境温度的影响。  

# 510 与汇流排相连  

如果预计到会有相对移动，汇流排与设备、汇流排的各部分以及不同装置之间的电气连接应有柔韧性。  

采用合适的装配方式，并用螺栓连接来保持机械力在设备寿命期内近似为常数，包括任意的材料蠕变。

# 512 包括检测和修理的整修与维护规定  

根据EN 45545-5中72的规定，电气设备的修改不应对原始的燃烧安全性规范有负面影响。新型机车车辆的设计应考虑在寿命期内可能要承受的大型整修(重新设计或改进设计)或大型修理的平均次数。  

设计应包括下述规定，  

———应容易接近电缆、电缆线槽、设备、端子等;  

注1该规定对检测用途也是必需的。  

一应有允许更换和修理电缆的规定(如应留有足够空间以确保能进行电缆连接、能在线槽内敷设新的电缆等)。  

注2这些规定对调试时的修理与更换是必要的。  

敷设在管内的电缆不应固定在一起形成一束，否则会需要大量的工作来重新布置各电缆。同样的原因,套管的弯曲半径与截面积均应尽可能大。为增强可接近性,可采用断续的套管(带孔、裂口等的套管)。  

使用时(如车与车之间的连接等)承受弯曲应力的电缆应具有良好的易接近性。敷设电缆的挠曲部分与固定部分之间的过渡应尽可能平滑。  

对于敷设在管道内或槽内的电缆，含备用线的实际电缆数量与可在直管或槽内敷设的最大可能的电缆数量之比不应大于 $60\%$ ，以方便更换和整修。  

如果上述有关电缆被固定(即使用时不能移动、弯曲或卷曲),对于截面积不大于6mm²的导体,在修理与整修时可以使用绝缘的拼接连接器。参见5.17有关端接导体的要求。  

对于新造的机车车辆，不能在原始设计或制造中使用编接。  

应仔细选择敷设电缆的分离点，并由制造商与买方同意。选择的分离点应使在修理或定期维修时，尽可能不拆卸敷设好的电缆。短预期寿命的电缆(如车辆间的挠性电缆)应易于换新,尽可能不需要拆卸。  

# 513 防火、电缆敷设与布线后的燃烧性能  

电缆与布线材料有关火势蔓延、阻燃与燃烧反应(如含烟量)的详细内容，见EN 50355中第5章。  
通常，EN 45545(系列标准)，尤其是EN45545-5中第6章适用于与火灾隐患有关因素。  

对于某些关键功能(应急灯控制、车门控制、紧急制动、灭火器控制等)，应使用带有特殊结构的电缆、拼接连接器、终端和连接器，该结构应能在燃烧时保持电缆的完整性一定时间。EN 50200适用于这些相关内容。

# 514 控制电缆备用规定  

连接机车车辆内部不同位置电气设备的电缆，每束含10根绝缘线芯以上的多芯电缆和束合电缆应留有10%或至少2根备用绝缘线芯。应在连接部件(插头、阴性或阳性接头、端子、耦合接点等)中留有相应数量的备用接点，或为额外增加的连接部件留有可用空间。  

注1本条款不适用于专用电缆，如开门按钮、照明控制电缆，屏蔽数据总线或其他通信系统电缆。  

备用绝缘线芯的数量应与机车车辆最初组装完工时提供的数量相同。  

备用绝缘线芯的数量取决于电缆、连接器的结构以及电缆的敷设方式。在电缆不可触及的情况下(如管道内),应增加备用绝缘线芯的数量。关于连接器内的备用部分，如插头或插头内的针，应由制造商与买方同意是否在插座内安装备用件或是否提供单独的部件及其安装工具，以防今后更换整个插头。  

除非制造商与买方之间另有规定，备用绝缘线芯的末端应卷起并固定在可触及的位置。  

注2出于安全原因或EMC目的，允许对备用绝缘线芯进行其他处理,包括使末端绝缘或将其接地。

# 518 热缩套管的使用  

机车车辆上使用的热缩套管有如下两种用途：标识用(通过颜色、自身带有的标记或在适当位置的额外标记);电气或机械保护用(例.防水和永久性地保持特定的电气间隙与爬电距离)。  
如果热缩套管用于绝缘，则应仔细选择以确保·机械与电气性能与热缩套管所代替的绝缘材料相同;壁厚与它所代替的绝缘线芯或电缆类似(见注1)。

注2 只有当非绝缘部分很短时才可使用套管包覆，否则电缆会丧失柔韧性,防火性能改变,冷却条件受影响。  

注3使用热缩套管时,不应超过电缆材料允许的最大短时温度(短路温度)。  

根据 EN45545-1第6章和表1,所使用的热缩套管根据防火性能应限制在一定的机车车辆工作种类,种类应在买方的订货单中规定。

# 66 屏蔽与接地  

为减小辐射,可对A类电缆进行屏蔽。为增强抗扰度,如果子系统制造商推荐,则应对C类电缆进行屏蔽。预计会有较高的电磁骚扰水平的情况下，应对各类电缆进行屏蔽。  

注可通过屏蔽绝缘线芯或电缆或用金属箱来完成屏蔽铠装。  

当屏蔽接地时,屏蔽区域应尽可能大(即低感连接)。如果有其他可行的方案,不应使用屏蔽层接出一根单线并通过连接器针脚接至接地点的方式。  

通常，电缆的屏蔽两端均应接地(参见附录I)。  

应草拟一接地方案以补偿由于屏蔽接地点之间的电压差所引起的回流，确保该电流不能流经屏蔽层。  

TB/T 3153—2007

# 67 蓄电池的供电连接  

对蓄电池侧有脉冲整形或脉冲控制负载组件的蓄电池供电电缆,必要时应互相独立。其他供电电缆的分支应尽可能地靠近蓄电池。  

# 6.8 数据总线  

数据总线应通过专用连接器进行连接，但在有其他连接方案时可以例外(如在机车车辆自动车钩里)。  

不同的数据总线应通过一公用专用连接器进行连接，其绝缘线芯在连接器中的连接应尽可能使不同的数据总线相互分开。  

注·这可在插头座内留有备用空间。  

数据总线的屏蔽层断开将导致信号对称度失去平衡。因此，从一个设备到另一个设备的数据总线连接应无中断,即应尽量避免使用终端与插头。子系统制造商应详细说明这些特殊规则。

# 8.21总则  

在连续的敷设有电缆的机车车辆或组件上，试验应在所有敷设电缆的机车车辆或组件上进行。

所有性能试验应在电绝缘试验之后进行。  

应通过施加8.22与82.3所描述的介电强度试验与绝缘电阻测量来验证绝缘完整性。

# H2 样品试验  

膨胀状态和自由恢复状态的样品均放置在平直的支撑物上，然后用软铅笔橡皮进行摩擦。  

摩擦时，将橡皮紧紧压在标记上，并对整个标记长度从头到尾进行摩擦。试验时应使用最大可能的人力。  

标记应能承受10次橡皮的来回摩擦,每次摩擦的时间应为2s或3s。  

# H3 试验结果  

在样品经过试验后，标记应在正常光线下清晰易读。
