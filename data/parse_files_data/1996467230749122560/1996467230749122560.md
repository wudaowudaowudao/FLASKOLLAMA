# 重庆高速公路清障救援管理办法  

# 第一章 总则  

第一条为规范重庆高速公路清障救援服务管理工作，根据《中华人民共和国公路法》《中华人民共和国道路交通安全法》《重庆市公路管理条例》《发展改革委交通运输部关于规范高速公路车辆救援服务收费有关问题的通知》《重庆市物价局重庆市交通委员会关于高速公路清障救援服务收费及管理有关问题的通知》等规定，特制定本办法。  

第二条本办法适用于重庆高速公路清障救援管理工作  

# 第二章 定义和职责  

第三条　高速公路车辆救援服务是指高速公路经营管理单位受当事人委托，将发生故障或事故的机动车拖移至指定地点并收取相关费用的行为。  

其服务范围包括将故障或事故车辆拖移至就近高速公路出口处、服务区、公安交巡警或交通综合执法指定地点。  

第四条重庆高速公路运行管理委员会负责指导、协调、监督、考核高速公路清障救援管理工作，制定高速公路清障救援管理制度。  

第五条 高速公路经营管理单位是清障救援服务主体，事故车辆、故障车辆清障救援服务由路段所属高速公路经营管理单位统一组织实施。  

高速公路经营管理单位应成立清障救援业务管理部门、清障救援调度中心（可由路段监控中心兼）、清障救援队伍（原则上应驻点在高速公路收费站或服务区）  

第六条高速公路经营管理单位应建立专职救援队伍或者委托社会救援机构（外协单位）开展清障救援工作。外协单位须具备相应施救作业经验，相关人员须经过专项业务和安全教育培训，具备救援服务技能。外协单位应遵守重庆高速公路清障救援服务的各项管理规定。  

第七条‧高速公路经营管理单位管辖路段清障救援力量不足时，可请求邻近高速公路清障救援队伍临时协助。经邻近高速公路经营管理单位同意后，由清障作业点所在高速公路经营管理单位具体组织实施，邻近高速公路派出的清障救援队伍应服从其指挥调度。  

第八条　重庆高速公路清障救援服务收费应严格遵照行业主管部门公布的收费标准执行。  

# 第三章 配置标准  

第九条高速公路经营管理单位应合理设置清障救援点，每个清障救援点辐射半径不宜大于25公里。  

在特大桥、特长隧道、隧道群及事故多发路段应优先考虑设置清障救援点。  

在春运、节假日等时段，有条件的路段可临时增加、前置清障救援点。  

第十条清障救援点应设清障救援人员 24小时值守。出勤作业时必须两人一车、由救援点出发，着统一的工作服和反光背心（或带有反光条的工装)，佩戴现场记录仪。吊车起吊作业过程中，还应佩戴安全头盔。  

第十一条 清障救援点车辆推荐配置标准  

每个清障救援点的基本配置为8吨及以下清障车1辆，20吨及以上清障车1辆。管理里程超过80公里的经营管理单位应配置1台吊车。  

清障救援点覆盖范围内，断面日均车流量在1.5万-3万辆的，在基本配置基础上增配1辆清障车（吨位按实际情况确定)；断面日均车流量大于3万辆的，在标准配置基础上增配2辆清障车（吨位按实际情况确定）。  

驻点清障车应性能良好，满足清障救援作业工况需要。每辆清障车应至少配车载GPS、车载移动视频、收费标准文件、反光锥形筒（不低于20个）标牌、车辆警示灯，车身应标明单位名称和联系电话。  

# 第四章 管理规范  

第十二条清障救援调度中心统一调度清障救援队伍，清障救援队伍的人员和车辆具体实施清障救援作业服务。  

第十三条 高速公路清障救援应在保障自身安全、规范操作的基础上高效处置。若遇无法拖移的情况，应立即报清障救援调度中心和公安交巡警协助处置。  

第十四条清障救援调度中心、清障救援人员在岗期间，应按要求规范使用开放式一键救援平台。  

第十五条‧清障救援调度中心、清障救援人员在接到报警求助信息（含开放式一键救援平台信息）时，需详细询问（查看）待施救车辆的联系方式、车牌号、车型、吨位、受损部位及所在位置，并做好详细记录。  

同时，清障救援调度中心将清障救援信息告知路巡人员、辖区公安交巡警。  

第十六条在接到清障救援调度指令后，清障救援人员应立即响应，无特殊情况白天5分钟内、夜间10分钟内出动。  

第十七条清障救援人员到达施救现场后，按《道路车辆清障救援操作规范》（JTT891-2014）《重庆高速公路清障作业操作指南》要求及现场指令实施清障救援作业。  

第十八条清障救援人员在提供清障救援服务前应主动向当事人出示收费标准文件，告知服务项目和收费金额。清障救援服务结束后，应按收费标准文件告知当事人收费金额。  

未列入的收费项目，清障救援人员与当事人按市场价格和公益原则协商确定收费标准，并签订书面协议。  

收取车辆清障救援服务费用应向当事人提供足额、合法、有效的收费票据。  

第十九条拖移故障车辆原则上拖移至就近收费站出口处，当事人要求转移至其他停放点的，或具体事项不属于车辆救援服务主体职责的，在保障高速公路应急救援需求前提下，当事人与清障救援人员可按市场价格协商服务费用，并签订书面协议。  

第二十条清障救援人员应严格执行工作保密制度，未经同意不得对外发布清障救援作业情况、突发事件处置现场等工作相关信息。  

# 第五章 服务监管  

第二十一条在清障救援服务过程中，清障救援人员应着装统一、规范整洁；与当事人沟通时应表意清楚、用语文明，不得出现粗鲁、谩骂的语言；不得有抽烟、吃零食、嬉笑打闹等失态行为。  

第二十二条　高速公路经营管理单位依托开放式一键救援平台对清障救援服务开展服务满意度回访。若当事人不满意的，经营管理单位应在1个工作日内进行电话回访，并做好记录。  

第二十三条高速公路经营管理单位应加强安全管理，按规范对清障救援人员开展安全培训、岗前安全教育，并做好相关记录。  

由外协单位承担清障救援作业的，经营管理单位应在协议中明确安全管理职责和要求，并做好监督。  

第二十四条高速公路经营管理单位每季度至少开展一次清障救援培训（演练)，不断提高清障救援管理水平和现场处置  

能力。  

由外协单位承担清障救援作业的，由外协单位具体实施培训（演练）工作，经营管理单位应做好监督。  

第二十五条高速公路经营管理单位应加强清障收费监管，严格财务纪律，杜绝乱收费现象。  

第二十六条‧高速公路经营管理单位应建立并规范清障救援内业资料，保证数据准确、及时、完整填报。  

# 第六章 附则  

第二十七条本办法由重庆高速公路运行管理委员会办公室负责解释。  

第二十八条 本办法自发布之日起实行。

# 重庆高速公路清障救援作业操作指南  

本文根据《道路车辆清障救援操作规范》（JTT891-2014）《道路车辆清障救援技术要求》（JTT1357.1-2020）等规范制定，旨在规范重庆高速公路清障救援作业操作。若上级制度文件、行业规范有新增或更新，应以最新规范要求为准。  

# 1一般故障（事故）现场车辆清障作业操作规程  

1.1清障救援人员当班期间，必须着统一的工作服。出勤时，应穿着反光背心或带有反光条的工装，佩戴现场记录仪。夜间或雨、雾天气还应佩戴LED肩灯。  

1.2清障救援人员接到清障救援调度指令后应立即响应，对车辆进行出车前检查，确保车辆技术状况良好及随车设施设备工具完备，开启清障车示警灯（夜间或雨雾天气还应同时开启示廓灯、后位灯），无特殊情况白天5分钟内、夜间10分钟内出勤。  

1.3到达现场后，需首先鸣响警报、观察四周，确定安全后下车。下车后第一时间对作业现场进行观察，预设紧急情况下的逃生路线，确保能及时、有效地向安全地带撤离。  

1.4作业前，应使用反光锥形筒和反光标志牌隔离作业区域。从现场区域来车方向150米外至作业现场连续摆放反光锥形筒，反光锥形筒的间距不超过10米，反光标志牌在作业隔离区  

的最远端摆放。  

1.5设置好安全隔离区域后，安排人员在来车方向进行警戒，所有人员必须在安全隔离区域内活动，保持警惕，注意自身安全。  

1.6同时，清障救援人员引导故障（事故）车辆驾驶员及乘客前往安全区域，并对故障（事故）车辆进行检查并登记，确定车辆清障救援方案，出示收费标准，征得被服务方同意。若救援有可能对故障（事故）车辆造成二次损坏，需征得被服务方同意并做好记录。  

1.7 在确保安全的前提下，对现场进行照相取证。  

1.8清障作业前，需切断故障（事故）车辆的电源。故障（事故）车辆有燃料或滑油外溢时，在清障作业前应采取相应处理措施，避免清障救援过程中发生二次事故。  

1.9对故障（事故）车辆进行固定，并解除其制动装置，将挡位置于空挡。此过程中，部分大型货车可能需要完成松断气刹等作业，对此，清障救援人员无法完成的，需及时、提前将信息上报辖区清障救援调度中心，以便尽快调度维修人员赶赴现场协助处置。  

1.10 对清障车辆采取以下安全措施：  

1.10.1在松软地面上工作时，应将地面垫平、压实，保障清障车自身安全稳定;  

1.10.2 清障车辆在坡道上停放时，应采取防溜坡措施。  

1.11如因作业需要卸货的，应在确保安全及条件允许的前提下，应先将货物卸到安全区域。  

1.12 清障救援作业应按"3.清障车操作规程"相关要求开展实施。  

1.13在开展一般事故现场车辆情况作业过程中，若发现故障（事故）车辆起火或其他突发问题时，应立即停止作业，在保障自身安全前提下采取有效措施控制事态。同时向清障救援调度中心上报，积极联络有关部门处置。  

1.14现场清障作业完毕后，应由作业现场中心位置向来车方向最远端依次撤除反光标志牌以及反光锥形筒。  

1.15开始、结束拖移时均应向被服务方确认清障车辆起止里程数及实际服务里程，并按收费文件标准计算实际收费金额。  

1.16故障（事故）车辆应拖移至就近高速公路出口处、服务区、公安交巡警或交通综合执法指定地点。  

1.17在保障高速公路救援力量充足的前提下，如确需发生延伸服务，由被服务方现场提出申请，填写《重庆高速公路清障车延伸服务申请书》，并确认延伸服务里程数及金额，继续提供有偿拖运服务，但不得强行拖移车辆到指定的场所进行维修。  

1.18作业完毕后，清障救援人员需请被服务方在清障记录表上签字，并存档。  

1.19清障救援车结束服务后应立即返回清障救援驻点，检查随车物资、装备、车况，确保处于待命状态。  

1.20一般故障（事故）现场车辆清障作业布控示例见附件1。  

# 2 特殊情况清障作业操作规程  

2.1　在高速公路实施车辆清障作业过程中，存在隧道故障（事故）弯道故障（事故）、收费广场故障（事故）危化品车辆故障（事故）车辆火灾事故、夜间和雨雾天气等特殊情况，清障救援人员在实施清障作业过程中，应以“1.一般故障（事故)现场车辆清障作业操作规程"为基本要求，并根据现场情况，按以下要求做好各种特殊情况的现场清障作业。  

2.2 隧道故障（事故）现场车辆清障作业  

2.2.1清障救援人员在收到隧道故障（事故）救援信息后，如是一般事故或故障，且公安交巡警未赶赴故障（事故）现场的情况下，操作流程如下：  

2.2.1.1通知辖区路段监控中心更改事故隧道相应车道指示器、洞口三色灯、隧道照明，同时通过隧道和上游可变情报板发布提示信息。  

2.2.1.2清障车辆驶入隧道，在开启示警灯基础上，还应开启示廓灯、后位灯，清障救援人员还应佩戴LED肩灯并保持其闪烁状态。  

2.2.1.3从现场区域来车方向200米外至作业现场连续摆放反光锥形筒，反光锥形筒的间距不超过10米，反光标志牌、手持频闪警示灯在作业隔离区的最远端摆放。  

2.2.1.4 隧道交通严重拥堵、车流量大等可能对清障作业造成安全影响时，应建议公安交巡警采取临时交通管制措施  

2.2.2如隧道发生火灾事故、危化品车辆事故、较严重交通事故、造成两条及以上车道封闭的事故，且公安交巡警人员赶赴现场的情况下，操作流程如下：  

2.2.2.1 在公安交巡警指挥下，将清障车辆停放在安全地带  

2.2.2.2待现场公安交巡警、消防、应急等相关部门确认作业现场处于安全状态后，按其指令进入隧道事故现场实施作业。  

2.2.3 隧道故障（事故）现场车辆清障作业布控示例见附件2。  

2.3 弯道故障（事故）现场车辆清障作业  

2.3.1在实施弯道故障（事故）现场车辆清障作业时，从现场区域来车方向200米外（且至少摆放至入弯头处）至作业现场连续摆放反光锥形筒，反光锥形筒的间距不超过10米，反光标志牌在作业隔离区的最远端摆放。  

2.3.2夜间、雨雾天气、交通严重拥堵或其他情况可能对清障救援作业造成安全影响的，应建议公安交巡警部门采取临时交通管制措施。  

2.3.3 弯道故障（事故）现场车辆清障作业布控示例见附件3  

2.4 收费广场故障（事故）现场车辆清障作业  

2.4.1在实施收费广场故障（事故）现场车辆清障作业时，清障救援人员应先通知收费站关闭故障（事故）车辆所在车道，并通知收费站工作人员做好收费广场的交通疏导工作。  

2.4.2 根据收费广场的实际情况，在确保安全的情况下，对现场区域建立足够距离的安全区域，并在安全区域最远端摆放反光标志牌。  

2.5 危化品车辆故障（事故）现场车辆清障作业  

2.5.1在现场公安交巡警、消防、应急等部门的指挥下，将清障车辆停放在安全地带。  

2.5.2　待现场公安交巡警、消防、应急等相关部门确认作业现场处于安全状态后，按其指令进入事故现场实施作业  

2.5.3做好作业现场勘查，确定救援作业方案，救援作业方案应报公安交巡警或应急部门的同意。若在清障作业过程中发生危化品泄露、起火等异常情况，应立即停止作业并撤离至安全地带，并做好相关信息上报工作。  

2.5.4在危化品车辆起吊、拖拽时，应在安全员监护下实施  

2.6 火灾事故现场车辆清障作业  

2.6.1在现场公安交巡警、消防、应急等部门的指挥下，将清障车辆停放在安全地带。  

2.6.2在公安交巡警、消防、应急部门的指挥下，经相关部门确认车辆火灾已经被扑灭并且现场处于安全状况后，方可进入事故现场实施清障作业。  

2.6.3做好作业现场勘查，确定救援作业方案，救援作业方案必须经公安交巡警或应急部门的同意，如在救援作业过程中发生车辆起火、爆炸等异常情况，应立即停止作业并撤离至安全地带，并做好相关信息上报工作。  

2.6.4在火灾车辆起吊、拖拽时，应在安全员监护下实施。  

2.7 夜间和雨雾天气车辆清障作业  

2.7.1实施夜间或雨雾天气清障作业时，清障车辆在开启示警灯基础上，还应开启示廓灯、后位灯和照明设备。清障救援人员还应佩戴LED肩灯并保持其闪烁状态。  

2.7.2从现场区域来车方向200米外至作业现场连续摆放反光锥形筒，反光锥形筒的间距不超过10米，反光标志牌、手持频闪警示灯在作业隔离区的最远端摆放。  

2.7.3交通严重拥堵或其他情况可能对清障救援作业造成安全影响的，应建议公安交巡警部门采取临时交通管制措施。  

# 3 清障车操作规程  

3.1 清障车背载操作  

3.1.1 平板装载前的准备  

3.1.1.1 将清障车开至被背车正前方合适位置。  

3.1.1.2清障救援人员在平板装载前，应对被背车进行检查，重点包括车辆型号、损伤情况、车重、变速箱换挡形式、行驶系统（含轮胎）档位、手刹、灯光等情况，并确定施救方案，告知被服务方，如清障作业有可能对车辆造成二次损失，需征得被服务方同意。  

3.1.1.3将被背车熄火、开启危险警示灯，如发现被背车有燃油或润滑油外溢时，应立即切断被背车电源，在确保安全的情况下采取相应处置措施，避免清障作业过程中发生二次事故。  

# 3.1.2 平板装载  

平板装载的流程为：结合取力器、滑出平板、释放钢丝绳、连接牵引钩（环）、牵引被背车、车辆固定、平板回位。  

3.1.2.1 在操作取力器时，打开或关闭取力器，必须先踩下离合器踏板，使离合器分离，不得强制啮合。  

3.1.2.2在滑出、倾斜平板时，应先将平板伸缩缸伸出，以解除平板限位，同时，要合理掌握折叠板与地面的角度，特别是超低底盘、前悬较长、接近角较小的车型，要适当降低折叠板与地面的角度，避免前保险杠、排气管等触碰平板。  

3.1.2.3严格按照被背车使用要求安装牵引钩（环)，如在牵引过程中发现牵引钩（环）钢丝绳等异常，应立即停止作业。  

3.1.2.4在牵引被背车前，应解除被背车驻车制动、挂空档。在牵引过程中，应安排人员操作操纵机构并观察被背车行驶方向，通过操作方向盘控制车辆行驶方向，避免被背车轮胎碰到平板边缘，甚至越过平板边缘。  

3.1.2.5在被背车牵引到位后，平板由折叠状态变为直板状态且未放平时，应采用绑带和紧固器对被背车四条轮胎进行“八字形"捆绑，绑带应尽量少扭曲，紧固器使用后应将手柄打到折叠状态，绑定后轮时，清障队员应在车辆侧面操作。待平板完全回位后，应通过放置三角木、三角铁固定轮胎，防止被背车移动。  

3.1.2.6车辆固定好后，被背车拉紧驻车制动，并检查绞盘钢丝绳是否稳固、牢靠。  

3.1.2.7在装载被背车的过程中，特别是平板倾斜负载时，被背车后方不得站立人员，平板移动过程中，平板下方不得有人员移动、蹲、卧。  

# 3.1.3 平板卸载  

平板卸载的流程为：结合取力器、滑出、倾斜平板、解除车辆固定、释放钢丝绳、牵引被背车、平板回位。  

3.1.3.1确认钢丝绳牵引钩、绑带牢靠后，将平板滑出、倾斜，直至平板尾部滚轮刚刚触地、板面尚未折叠时（整个板面正好处于一个平面)，松开被背车的绑带，再将平板完全滑出，使平板与地面形成折叠。  

3.1.3.2解除被背车驻车制动，操作绞盘放钢丝绳，使被背车驶离平板板面。被背车完全落地后，确认被背车的驻车制动已拉起，再松开被背车的牵引钩。  

3.1.3.3缩回平板并放平、滑入到最前端，把取力器开关置于分离位置，再将钢丝绳收好（钢丝绳不能下垂掉落在板面上，应拉直)，有序卷好绑带并放入工具箱内。  

3.1.3.4在卸载被背车的过程中，特别是平板倾斜负载时，被背车后方不得站立人员，平板移动过程中，平板下方不得有人员移动、蹲、卧。  

# 3.1.4 辅助轮的使用  

# 3.1.4.1 架装辅助轮  

辅助轮趴在地面上，将其沿着后轮塞进车底部。用撬棍对套入“牛角"将辅助轮一端抬起，并插上插销。  

# 3.1.4.2 辅助轮在板面上行驶  

辅助轮负载后，在上、下板过程中，要注意辅助轮刚上板面、将离开板面时，速度要放缓，不可因速度过快而出现绷开、跳胎、滑落等现象。同时，需注意辅助轮轮胎与平板边梁的间隙，避免辅助轮轮胎碰到平板边缘，甚至越过平板边缘。  

# 3.1.4.3 卸载辅助轮  

先松开定位插销，用撬棍将辅助轮松开，使架装辅助轮的轮胎落地。从车底移出辅助轮，将辅助轮复位，插好定位插销，放置在平板前端，并用锁紧销锁住。  

# 3.2 清障车拖拽（牵引）操作  

3.2.1 抱胎托举前的准备  

3.2.1.1将清障车开至被托车正前方合适位置，与被托车成一直线，拉手刹，此时清障车后端应预留托臂折叠放平后所需要的距离。  

3.2.1.2清障队员在托举装载前，应对被托车进行检查，重点包括车辆型号、损伤情况、车重、变速箱换挡形式、行驶系统（含轮胎）档位、手刹、灯光等情况，并确定施救方案，告知被服务方，如清障作业有可能对车辆造成二次损失，需征得被服务方同意。  

3.2.1.3 将被拖车熄火、开启危险警示灯，如发现被拖车有燃油或润滑油外溢时，应立即切断被拖车电源，在确保安全的情况下采取相应处置措施，避免清障救援过程中发生二次事故。  

# 3.2.2 抱胎托举装载  

托举装载的流程为：结合取力器、放平折叠臂、抱住轮胎托起车辆、调整高度和前后位置、捆绑轮胎。  

3.2.2.1操作清障车操纵杆，使折叠托臂使之与地面水平，托臂最下端离地约 $20\sim50\mathrm{mm}$ 。根据被拖车的轮距，调整好L型抱胎机构的横向距离，将 $\mathrm{~L~}$ 型抱胎机构缓缓伸入被拖车底部前轮前，尽可能将其紧贴轮胎前轮廓。  

3.2.2.2用L型抱胎机构的托架套住被拖车的轮胎，托架的横管尽可能紧贴轮胎后轮廓，旋转合上安全锁的插销，将被拖车缓缓提升到可行驶的高度。  

3.2.2.3操作托臂伸缩油缸，在留足被拖车安全转向所需的空间后，尽可能地将被拖车拉前。确认提升高度和前后位置都符合安全托牵行驶要求后，用绑带将轮胎与L型抱胎机构捆绑在一起。  

# 3.2.3 抱胎托举卸载  

托举卸载的流程为：结合取力器、放下被拖车、解除绑带、托臂回位。  

3.2.3.1在操作取力器时，打开或关闭取力器，必须先踩下离合器踏板，使离合器分离，不得强制啮合。  

3.2.3.2 操作托臂操纵杆，降低托臂使被拖车前轮着地，拉  

好被拖车的手刹，解除绑带，并有序卷好绑带放回工具箱内。  

3.2.3.3拔出L型抱胎机构的托架，将托架放好归位。缩回托臂，调整好十字臂套，并合上锁紧插销，将托臂回位，最后将取力器开关置于分离位置。  

# 3.3 托牵行驶  

3.3.1 托牵行驶前的准备  

3.3.1.1在被背车、被拖车完成固定作业后，应把取力器开关置于分离位置，方可实施托牵行驶，否则会损坏清障车液压系统。  

3.3.1.2检查、确认被拖车手刹是否松开，档位是否在空档;检查、确认被背车、被拖车的捆绑是否牢靠（用手试压绑带，感觉其松紧度)。  

3.3.1.3清障车开启警灯，被背车或被拖车开启危险警示灯，如被背车或被拖车无法开启危险警示灯，应在被背车或被拖车尾部悬挂警示标志（反光布或反光牌）或移动危险警示灯。  

3.3.1.4气压制动的车辆，当气压不足时，存在刹车自动抱死的现象。解决的方法有以下两种：一是用输气管道将清障车和被拖车的气压通道连接起来，利用清障车气压推开被拖车的刹车自动抱死装置；二是使用工具解开被拖车刹车分泵的调整锣丝，从而解除刹车自动抱死装置的作用（需急救单位协助完成）  

# 3.3.2 托牵行驶  

3.3.2.1 起步时，离合器处于半联动状态，用一挡缓慢起步，  

至感到稍有阻力时，应保持足够的动力平稳行进，  

3.3.2.2行驶时，应紧靠道路右侧行驶，行驶速度保持平稳由于清障车、被拖车连接在一起，其动力性能改变和惯性作用增强，应避免紧急制动和急转弯。  

3.3.2.3 行驶至弯道时，应预估清障车与被拖车的偏移幅度，适当加大转弯半径，同时使用喇叭、灯光，引起来往车辆的注意。  

3.3.2.4倒车时，应尽量避免两车（清障车与被拖车）纵轴线之间的夹角太小；若过小可能对两车造成损伤。  

# 4清障作业服务要求  

# 4.1 清障作业六不准  

4.1.1 警戒范围标志未设置好不准操作;  
4.1.2 钢丝绳周围站人不准操作；  
4.1.3 清障车与被拖车之间有人不准操作;  
4.1.4 清障车安全装置失灵不准操作;  
4.1.5 被拖车、货物上有人或货物捆扎不牢不准操作;  
4.1.6 夜间作业现场没有照明或照明不足不准操作。  

# 4.2 清障作业八不拖  

4.2.1 被清障车重量不明和超重不拖;  
4.2.2 斜拉、横拉、车身位置不正不拖;  
4.2.3 车辆轮毂或货物着地不拖;  
4.2.4 被拖货车、货物上有人或货物捆扎不牢不拖;  
4.2.5 易燃易爆物品没有安全措施不拖；  
4.2.6 驾驶员或随车人员未安置好不拖;  
4.2.7 被拖车辆准备工作未做好不拖;  
4.2.8 清障车与被拖车连接不牢固不拖。  
4.3 清障作业现场严禁烟火；无关人员不得进入清障作业现场。
