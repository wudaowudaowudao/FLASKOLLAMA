# 重庆高速公路集团有限公司关于印发 《高风险业务管理办法（试行》的通知  

集团总部各部门、分公司，全资及控股子公司：  

为进一步加强重庆高速公路集团有限公司高风险业务监督管理，规范高风险业务投资行为，防范经营风险和财务风险，建立"管控严格、操作规范、风险可控"的高风险业务监管体系，集团根据重庆市国有资产监督管理委员会《关于切实规范和加强企业高风险业务监督管理的通知》（渝国资〔2020）91号）集团《"三重一大"事项集体决策实施办法》《授权管理办法》等有关规定，结合集团实际情况，制定《高风险业务管理办法（试行）》。经过集团2020年第23次党委会、2020年第9次总经理办公会前置研究，集团七届四十二次董事会审议通过，现予以下发，请遵照执行。

# 重庆高速公路集团有限公司高风险业务管理办法（试行）  

# 第一章 总则  

第一条为进一步加强重庆高速公路集团有限公司（以下简称集团)高风险业务监督管理，规范高风险业务投资行为，防范经营风险和财务风险，建立"管控严格、操作规范、风险可控"的高风险业务监管体系，根据重庆市国有资产监督管理委员会《关于切实规范和加强企业高风险业务监督管理的通知》（渝国资[2020]91号）集团《"三重一大"事项集体决策实施办法》《授权管理办法》等有关规定，结合集团实际情况，制定本办法。  

第二条本办法适用于集团总部、分公司、全资及控股子公司（以下简称"操作主体”)  

第三条本办法所规范的高风险业务是指价值波动大、易发生损失、涉及金融及其衍生品交易的各类业务。具体包括以下类别：  

（一）买卖上市公司流通股、基金（货币基金除外）债券（国债除外、其他有价证券，不包括以参股、控股为目的的股权投资和以持有到期获取利息为目的的债券投资。  

（二)在境内外外汇交易市场上开展外汇交易业务，不包括正常贸易背景下的外汇买卖或外汇结算业务。  

（三)金融衍生业务，主要指商品类衍生业务（指以商品为标的资产的金融衍生业务，包括大宗商品期货、期权等)，货币类衍生业务（指以货币或利率为标的资产的金融衍生业务，包括远期合约、期货、期权、掉期等)，权益类衍生业务（股指期货、指数期权、个股等类似业务）  

（四)将资金、有价证券等金融性资产通过合约委托他人在境内外各类资本市场开展的非保本委托理财业务。  

（五）其他交易结构复杂，具有高杠杆性风险较高的业务。  

第四条对高风险业务的管理，应坚持审慎决策、规范操作、防控风险、注重实效"的原则。  

# 第二章 组织机构及职责  

第五条集团董事会为高风险业务的决策机构，负责核准各操作主体开展高风险业务的资格，审核年度投资计划及资金预算，听取年度工作报告，对重大应急事项方案进行决策。对于超出集团董事会权限范围的高风险业务，需报市国资委备案或审批。  

第六条集团经理层为高风险业务的统筹管理机构，负责对高风险业务进行有效管控，论证操作主体开展高风险业务的必要性，建立高风险业务管理制度，健全风险管理机制。集团分管风控法务工作的分管领导为高风险业务的分管负责人，具体负责高风险业务的统筹管理工作。  

第七条集团风控法务部是高风险业务的归口管理部门，负责法律审核管理，对业务实施过程中的风险进行监控；审计部是高风险业务的内审部门，负责违规经营投资行为问责及审计监督;计划财务中心负责高风险业务的资金监测，制定高风险业务会计核算制度，统一高风险业务会计政策；纪检监察部门负责高风险业务中违纪和职务违法行为的责任追究工作。  

第八条各操作主体是高风险业务的实施单位，负责开展高风险业务必要性分析、可行性研究、投资风险评估，建立健全高风险业务内部控制体系，编制投资方案，根据本单位相关制度对高风险业务进行审批，开展高风险业务。  

# 第三章 决策要求  

第九条各操作主体进行高风险投资业务需按照国家有关法律法规和本单位《章程》的规定，围绕经营目标，根据主营业务、资金实力和管理水平，结合本单位业务特点及承受能力等实际情况，按照"审慎决策、规范操作、防控风险、注重实效"的管理原则，慎重选择交易品种开展高风险业务。对于必须经有关部门批准许可的业务，应得到有关部门批准，并按照有关文件要求定期向有关部门或市国资委报备业务开展情况。  

第十条各操作主体开展金融衍生业务要严守套期保值原则，禁止任何形式的投机，要以降低现货风险口为目的，与现货品种、规模、方向、期限相匹配，与资金实力、交易处理能力相适应，不得从事风险及定价难以认知的复杂业务。具体要求如下：  

（一)除一、四类业务外，交易品种应当与主业经营密切相关，不得超越经营范围。交易工具应当结构简单、流动性强、风险可认知、符合套期会计原则处理要求。持仓时间应与现货保值所需计价期相匹配，一般不超过12个月或现货合同规定时间，不得盲目从事长期业务或展期。  

（二)开展商品类业务的，年度保值规模不超过年度现货经营规模的 $90\%$ ，其中针对商品贸易开展的金融衍生业务年度保值规模不超过年度现货经营规模的 $80\%$ 。时点净持仓规模不得超过对应实货风险口。要实行品种分类管理，不同单位、不同交易品种的规模指标不得相互借用、串用。套期保值对应关系的建立、调整和撤销应当符合生产经营的实际需要，避免频繁短线交易。  

（三)开展货币类衍生业务的，其规模、期限等应当在资金需求合同范围内，原则上应当与资金需求合同一一对应。  

（四）开展委托理财业务应对受托人资信状况进行调查与评价，选择信誉较好、资金实力雄厚、代客理财业绩优良的金融机构作为受托人，以安全性和收益性为重点，通过竞争性方式采购后签订委托理财合同。受托人必须为中国证监会或中国银保监会及境外监管机构批准具有客户资产管理业务、资金信托业务资格证书的银行、信托投资公司、证券公司、基金管理公司等金融机构。  

（五）新开展业务或以前年度因违规操作等产生资产损失的操作主体应当谨慎设定业务规模，进行适当压缩和控制。上一年度高风险业务累计损失超过利润总额 $10\%$ 的操作主体，下一年度高风险业务新增规模不得超过上一年度新增规模的 $50\%$ ·；上一年度高风险业务累计损失超过利润总额 $50\%$ 的操作主体，下一年度不得新增高风险业务规模。  

（六)建立科学合理的激励约束机制，对高风险业务盈亏进行综合评判，避免评价简单化、短期化，不得绩效考核、薪酬激励与高风险业务单边盈亏简单挂钩，防止片面强调单边盈利导致投机行为。  

第十一条 证券投资仅限于在国内证券交易所主板、中小板、创业板等发行的A股、B股股票及其衍生产品。设立的证券账户和资金账户应在相应的证券交易所报备相关信息，  

第十二条资产负债率高于市国资委重点监管线、连续3年经营亏损且资金紧张、盈余现金保障倍数低于1的单位不得开展金融衍生业务，其他业务审慎开展。  

# 第四章 操作规范  

第十三条各操作主体的高风险业务必须经本单位股东会（或有权机构，下同)审批后方可实施。高风险业务必须严格执行本单位"三重一大"事项集体决策程序，不得作为日常经营事项全权交予经营层。  

第十四条各操作主体应建立规范的授权审批制度，明确授权程序及授权额度，在人员职责发生变更时应及时中止授权或重新授权。  

第十五条各操作主体从事高风险业务应建立操作手册或合规手册，强化内控执行，严格合规管理，规范开展授权审批、交易操作、资金使用、定期报告。  

第十六条各操作主体财务部门负责高风险业务的资金管理和会计核算管理，根据集团统一的会计核算制度和金融工具确认、计量、金融工具列报等相关规定，规范高风险业务会计计量及核算行为，并在财务报表中正确列报。交易记录应全部备案，档案应保存10年以上。  

第十七条各操作主体从事高风险业务应遵守的原则：  

（一）有条件的单位应当设置风险管理部门、交易部门等，严格执行前中后台岗位、人员分离原则。建立健全定期轮岗、业务和职业道德培训制度。不单独设置部门的（财务部门必须单设），必须严格执行不相容岗位及人员分离原则。  

（二)本单位董事会负责交易授权审批。授权应当明确有交易权限的人员名单、交易品种和额度。人员职责发生变更时应当及时中止授权或重新授权。严禁单位负责人直接操盘。  

（三）交易部门或操作人员应当根据经批准的业务计划制定具体操作方案，按规定程序审批后操作。对于未经批准的操作方案，财务部门不得拨付资金，不得进行交易结算。  

（四)慎重开展场外业务。开展场外业务时，应当对交易工具、对手信用、操作程序、合同文本等进行单独的风险评估，审慎选择交易对手，规范场外交易保证金及结算。  

（五)对交易资金（含保证金)账户实行专门管理和定期监控，规范资金划拨和使用程序，加强日常监控，动态开展资金风险评估和压力测试。严格履行保证金追加审批程序。不得以个人账户（或个人名义)开展高风险业务，也不得单位账户借给他人使用以及帐外开展高风险业务。  

（六)建立定期业务进展报告、业务台账与财务核算对账等制度，确保高风险业务全流程有迹可循。风险管理部门、交易部门或操作人员至少每半年向本单位经营层报告高风险业务开展情况。  

第十八条开展高风险业务前应当做好项目可行性研究和投资风险评估，分析项目的可行性与必要性，及时上报突发事件及风险评估变化情况。  

第十九条从事高风险业务的专业人员应充分理解高风险业务类别的专业知识、风险及控制，严格执行业务操作手册和风险管理制度。  

第二十条从事高风险业务的应按不交叉原则设立高风险业务交易员岗和结算岗。交易员岗必须取得相关业务交易资格证书且为单位正式员工。结算岗负责账户的交易确认、结算，根据交易保证金和清算准备金的情况，不足时要及时办理补充保证金手续，以免违约情况的发生。  

第二十一条在进行金融衍生产品与非保本理财业务前，应当在多个市场与多种产品之间进行比较、询价，必要时刻聘请专业机构对待选的金融产品以及、非保本理财业务进行分析比较。  

第二十二条各操作主体根据每一年度生产经营计划确定高风险业务投资计划，制定投资方案，报本单位股东会审议批准后方可实施。  

# 第五章 风险管理  

第二十三条集团建立高风险业务垂直管理体系，各操作主体风险管理部门（未单独设置的由财务部门报告)独立向集团高风险业务归口管理部门上报风险和违规事项，归口管理部门再向集团高风险业务分管负责人上报。  

第二十四条各操作主体应当建立风险预警和处置机制，成立专门工作组织，制定详细的处置方案，妥善做好仓位止损、法律纠纷案件处置、舆情应对等工作，增加报告频率，防止风险扩大和蔓延。  

第二十五条采用风险坐标图等风险管理技术，通过定量和定性方法（定量方法以财务损失占利润总额的百分比，定性方法以财务损失)，识别市场风险、信用风险、操作风险和流动性风险。针对不同类型、不同程度的风险事项，明确处置权限及程序，1-2类由本单位经营层处置，3类以上由本单位股东会处置，4类以上启动风险应急处理机制。

第二十六条建立高风险业务审计监督机制，进行定期和不定期的审计。定期审计每年一次，与集团年度财务审计同时进行。  

# 第六章 报告制度  

第二十七条各操作主体应建立高风险业务报告制度，包括定期报告和专项报告，按照相关规定要求向集团归口管理部门上报，集团汇总后统一报送市国资委。  

第二十八条已开展高风险业务的操作主体应当按照季度定期报告，报告内容包括业务类型、交易品种、持仓规模、盈亏情况等。报送信息应做到及时真实准确，避免瞒报、漏报、错报。  

第二十九条对于高风险业务年度经营情况，各操作主体应当按照年度定期报告，报告内容包括年度业务开展情况（如业务品种、保值规模、盈亏情况、年末持仓风险评估、敏感性分析、未来趋势预判等）套期保值效果评估、审计检查中发现的问题及整改情况、其他重大事项等，以财务决算专项说明的方式随年度财务决算报告一并报送。对于未开展高风险业务的要进行年度“零申报”  

第三十条对于发生重大亏损、浮亏超过止损限额（单笔亏损金额不得超过投资金额的 $10\%$ ）被强行平仓等重大事项或发生重大法律纠纷等事项，各操作主体应当在事项发生后12小时内专项报告集团，集团在24小时内专项报告市国资委，并建立后续事项周报制度。  

# 第七章 责任追究  

第三十一条对于开展高风险业务产生重大损失风险、重大法律纠纷、造成严重影响的操作主体，要及时处置应对，并暂停开展高风险业务，依法依规开展追责问责。要根据《重庆市市属国有重点企业违规经营投资责任追究实施办法（试行》（渝国资发〔2018］12号）中共重庆高速公路集团有限公司委员会《关于印发违规经营投资责任追究实施办法（试行）》（渝高速党〔2018〕97号）及相关规定，对违规事项进行追责。  

第三十二条各操作主体开展高风险业务发生重大损失、造成严重影响等问题的，集团在业绩考核中予以扣分或降级处理。  

第三十三条各操作主体人员因违反法律法规或本制度规定无视风险擅自操作造成损失的，或由于工作失误或工作、失职造成损失的，由审计部门视情节轻重开展违规责任认定。涉嫌违纪或职务违法的，由纪检监察部门调查处理，涉嫌犯罪的，移送监察机关或司法机关。  

# 第八章 附则  

第三十四条本办法未尽事宜，依照国家有关法律、法规、  

规范性文件以及章程的有关规定执行。第三十五条本办法自2020年10月1日起实施。
