# 重庆高速公路集团有限公司关于印发重大经营风险报告规定（试行）的通知  

集团总部各部门、中心、分公司，全资及控股子公司：  

为落实市国资委《关于印发《关于加强市属国有重点企业内部控制体系建设与监督工作的实施意见>的通知》（渝国资[2020]134号)和《关于加强重大经营风险事件报告工作有关事项的通知》（渝国资〔2020）241号）工作要求，进一步建立健全集团重大风险管控机制，切实增强防范化解重大风险能力，集团制定了《重大经营风险报告规定（试行）》，经过集团2020年第21次党委会前置研究讨论和集团2020年第8次总经理办公会审议通过，现予以下发，请遵照执行。  

特此通知  

重庆高速公路集团有限公司2020年7月8日  

# 重庆高速公路集团有限公司重大经营风险报告规定（试行）  

# 第一章 总则  

第一条为落实市国资委《关于印发〈关于加强市属国有重点企业内部控制体系建设与监督工作的实施意见〉的通知》（渝国资（2020）134号）和《关于加强重大经营风险事件报告工作有关事项的通知》（渝国资〔2020〕241号）工作要求，进一步建立健全集团重大风险管控机制，切实增强防范化解重大风险能力，制定本规定。  

第二条 本规定适用于集团总部各部门、中心、分公司、全资及控股二级子公司。  

# 第二章 职责范围  

第三条集团总经理为向市国资委报告重大经营风险工作第一责任人。分公司及全资子公司总经理，委派到控股公司的董事长（执行董事、总经理)，委派到参股公司的第一高管为向集团报告重大经营风险的第一责任人。第一责任人负责组织建立健全报告工作机制，形成及时有效的报告工作体系。  

第四条集团分管内控（风险）管理工作领导人员，牵头负责推动内控（风险)管理与业务管理等相关部门加强工作配合和信息共享，建立上下贯通、横向协同的报送机制，保障报告工作  

体系有序高效运行。  

第五条集团法务审计部为报告工作牵头部门，集团各部门、中心、二级公司为报告工作实施责任主体。  

# 第三章 范围及程序  

第六条 重大经营风险事件报告范围  

（一)集团总部向市国资委报告范围。发生重大经营风险事件或内控缺陷，致使出现以下情形之一的，应及时报告：  

1.集团层面对实现年度经营业绩目标影响超过 $5\%$ 或造成人民币5000万元及以上重大资产损失风险。  

2．被司法机关或监管机构立案调查，主要资产被查封、扣押、冻结或企业面临行政处罚等，对企业正常生产经营造成重大影响。  

3.受到境外国家、地区或国际组织出口管制、贸易制裁等，企业国际化战略或国际形象产生重大负面影响。  

4.被境内或境外媒体网络刊载，造成重大负面舆情影响。  

5.其他需要报送的情形。  

（二)各二级公司第一责任人向集团报告范围。发生重大经营风险事件或内控缺陷，致使出现以下情形之一的，应及时报告：  

1.对实现年度经营业绩目标影响超过 $3\%$ 或造成人民币300万元及以上资产损失风险。  

2．被司法机关或监管机构立案调查，主要资产被查封、扣押、冻结或企业面临行政处罚等，对企业正常生产经营造成重大  

影响。  

3.受到境外国家、地区或国际组织出口管制、贸易制裁等，企业国际化战略或国际形象产生重大负面影响。4．被境内或境外媒体网络刊载，造成重大负面舆情影响。5.其他需要报送的情形。  

第七条 重大经营风险事件报告程序  

对于集团内部发现或外部监管机构、媒体网络反映的重大经营风险事件，发生主体单位应在事件发生24小时内书面报告集团。集团法务审计部应及时分类处理，需上报市国资委的，应在收到书面报告后2个工作日内书面报告。对于特别紧急的重大经营风险事件，应在第一时间，先以电话等方式报告。国家法律、法规对突发重大经营风险事件报告另有规定的，从其规定。  

第八条 重大经营风险事件续报  

重大风险事件出现以下进展情况，由事件发生主体单位在2个工作日内向集团法务审计部报送书面文件。集团法务审计部负责分类处理并按要求向市国资委报告。  

（一）相关风险事件出现重大变化或处置工作取得重要进展的。（二)对于需要长期整改落实的，由集团法务审计部纳入重大经营风险季度监测范围，并按季度向市国资委报送整改情况。（三）重大经营风险事件处置或整改工作结束后5个工作日内，由集团法务审计部向市国资委报送专项整改报告。  

# 第四章 责任追究  

第九条集团法务审计部负责对集团各部门、中心、二级公司重大经营风险事件报告和整改落实工作进行监督检查。对迟报、漏报、瞒报重大经营风险事件或落实整改工作不力的单位及责任人，将按集团有关规定追责问责。  

# 第五章 附则  

第十条集团全资及控股二级公司应对下设三级公司的重大经营风险进行管控，根据实际情况制定报告制度，对报告范围、报告流程、审批权限等进行规范明确。  

第十一条本规定由集团法务审计部负责解释，自印发之日起施行。
