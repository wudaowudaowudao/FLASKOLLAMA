# 欧洲标准前言

本文档（EN 16186-2:2017）由CEN/TC 256“铁路应用”技术委员会编制，其秘书处由DIN负责。

本欧洲标准应在2018年2月或之前以国家标准的形式发布，可以通过发布相同文本或认可的方式实现，并且在2018年2月或之前应撤销所有冲突的国家标准。

请注意，本文档的某些要素可能涉及专利权。CEN不承担识别任何或所有此类专利权的责任。

本文件是在欧盟委员会和欧洲自由贸易联盟授予CEN的任务下编制的，并支持欧盟指令2008/57/EC的基本要求。

有关与欧盟指令2008/57/EC的关系，请参阅信息性附录ZA，它是本文件不可分割的一部分。

EN 16186，《铁路应用——驾驶室》以EN系列的形式编写，涵盖了设计驾驶室时需要考虑的所有方面，从人体测量数据和可见性，到显示器、控制装置和指示器的集成，再到显示器的设计、驾驶室布局和通道设施。所使用的人体测量数据的背景信息在CEN/TR 16823 [2]中提供。

EN 16186，《铁路应用——驾驶室》目前包括以下部分：

第1部分：人体测量数据和可见性；
第2部分：显示器、控制装置和指示器的集成；第3部分：显示器的设计；
第4部分：布局和通道。

根据CEN-CENELEC内部规章，以下国家的国家标准机构有义务实施本欧洲标准：奥地利、比利时、保加利亚、克罗地亚、塞浦路斯、捷克共和国、丹麦、爱沙尼亚、芬兰、前南斯拉夫马其顿共和国、法国、德国、希腊、匈牙利、冰岛、爱尔兰、意大利、拉脱维亚、立陶宛、卢森堡、马耳他、荷兰、挪威、波兰、葡萄牙、罗马尼亚、塞尔维亚、斯洛伐克、斯洛文尼亚、西班牙、瑞典、瑞士、土耳其和英国。

# 介绍

本欧洲标准针对列车驾驶、调车以及相关的准备工作，就驾驶室界面而言。它提供了当前的驾驶室设计原则，并考虑了欧洲研究项目 EUDD+ [3] 提供的最新研究成果。

信息性附录 E 按照 EN 15380-4 [4] 的要求，用于需求管理。

在本文标准中未指定任何标准要求的情况下，它解决了需要在项目层面上进行规范或选择标准选项的需求。

# 1 范围

本欧洲标准适用于电力动车组 (EMU)、柴油动车组 (DMU)、客车、机车、驾驶拖车（驾驶车厢）。

注 1：本欧洲标准适用于《指令 2008/57/EC [1]》范围内的车辆。

本欧洲标准不适用于地铁、有轨电车和轻轨车辆。

EN 16186 的本部分适用于安装在驾驶室左侧、右侧或中央位置的驾驶台。

注 2：关于轨道交通管理系统 (OTM)，请参阅 EN 14033–1 [5] 和 EN 15746–1 [6]。

本欧洲标准提供了设计规则和指导，以确保在所有运行条件下（白天、夜晚、自然光或人工光）驾驶室内屏幕、控制和指示器的可见性和可操作性。

它涵盖四个方面：

— 屏幕、控制和指示器的特性，以确保适当的可见性：即亮度范围和对比度以及感知亮度的调整可能性；驾驶室内和驾驶台上的屏幕、键盘、控制和指示器的定位规则：即位置、可视角度等，并考虑正常的驾驶位置和工作环境（挡风玻璃、驾驶室内的自然光或人工光、不希望的眩光和反射等）；
— 麦克风和扬声器的特性和定位规则；
— 符号设计。

注 3：文本中的所有元素编号均指表 B.1。

# 5 司机室显示器、控制装置和运行功能指示器

# 5.1 概述

操作所需元素在附件 B 中展示。操作元素的符号应根据附件 C 提供。对于项目特定功能，应使用附件 D 的符号。

在以下文本中，三位数字指的是列出所有元素的表 B.1。

# 5.2 列车通信、监控和控制的显示或单元

车辆监控、车辆控制和列车通信应至少由以下台式设备提供：

004 - 控制命令显示器 (CCD)；
002 - 技术和诊断显示器 (TDD)；
001 - 列车无线电显示器 (TRD)。

对于列车无线电显示器，可以使用不同的解决方案，例如简化驾驶员界面。

如果添加了其他显示器（EMU/DMU 的附加 TDD、乘客信息系统显示器…），则不得阻碍前视性（根据 EN 16186-1）。

对于在国家内部使用的车辆，CCD 可以被具有相同功能的设备替代。

# 5.3 控制装置

# 5.3.1 对讲控制

为驾驶员单人操作单元设计的驾驶室，即除驾驶员外，车厢内无其他工作人员的单元，应符合EN 16683标准：

a) 用于支持“呼叫求助”功能的设备（例如麦克风）；
b) 用于确认呼叫求助的设备；
c) 用于取消与操作设备的通信链路的控制装置。

这些设备可以集成或与其他设备或功能结合使用。

# 5.3.2 外部乘客通道控制

如果为列车提供外部乘客通道（车门控制），则驾驶室应配备以下设备：

021 - 左侧车门释放及取消释放；
023 - 右侧车门释放及取消释放；
022 - 中央关闭所有车门。

# 5.3.3 驾驶室温度控制

应提供调节温度的手段。这应符合 EN 14813-1 和 EN 14813-2 标准。

# 5.3.4 车辆连接和断开控制

如果车辆配备自动连接器，驾驶室应配备用于管理连接功能的控制装置。 参见 EN 16186-3。

# 5.3.5 辅助控制台控件

如果配备了辅助控制台，则应包括以下操作元件：

013 - ATP 覆写；
015 - ATP 确认；
213 – 组合牵引/制动控制器，具有最低功能（T+，T，T-，SOS）或（T+，T，0，SOS）；
042 - 激活辅助牵引控制器，如果元件 033 - 行进方向“前进”；
和/或 035 - 行进方向“倒车”未提供。

作为可选配置：

021 - 释放和取消释放左侧车门；
023 - 释放和取消释放右侧车门；
213 – 组合牵引/制动控制器，具有一个或多个附加功能（T-，0，B̄，B，B+）；
033 - 行进方向“前进”；
035 - 行进方向“倒车”；

注：T+ 表示增加牵引设定点；T 表示恒定牵引设定点，T- 表示减少牵引设定点。0 表示任何设定点的降低。B- 表示减少制动设定点。B 表示恒定制动设定点，B+ 表示增加制动设定点，SOS 表示紧急制动。

侧面麦克风。以下操作元件应提供在或靠近辅助控制台：037 - 直接制动；038 - 喇叭；111 或 211 - DAC。

# 5.4 警告

# 5.4.1 由于安全系统而产生的警报

允许提供听觉和/或视觉警报以防止安全系统即将进行干预。

# 5.4.2 一或多扇外门紧急开启引起的警报

此要求仅适用于运营客运列车的EMU、DMU、驾驶车和机车。

应通过听觉和视觉警报向司机指示一或多扇乘客车门紧急开启。应能够确认并取消紧急车门开启的听觉信号。

# 5.4.3 司机与灭火系统的接口

如果配备了灭火系统，司机不得干预该系统。应在驾驶室内提供灭火系统已运行或不可用的信息。

# 5.4.4 由于速度降低而产生的警报

如果除了自动速度控制 (ASC) 之外的系统介入以降低列车速度，则应发出声音和/或视觉警报。

# 6 显示、控制和指示器的特性

# 6 显示、控制和指示器的特性

# 6.1 概述

# 6.1.1 设计原则

元件（例如形状、颜色、位置）的设计应有助于在所有环境光照条件下识别不同的功能。

作为控制和显示的设计参考，EN 894（所有部分）和 EN 1005（所有部分）可能适用。

# 6.1.2 阅读区域

为了允许在驾驶过程中在驾驶员台面显示所需的纸质文件，驾驶员座椅前方应提供至少为 $300\mathrm{mm}\mathrm{~x~}210\mathrm{mm}$ 的横向阅读区域。如果需要，该阅读区域可选择性地用作书写区域。应提供固定手段。如果这些手段未在台面上提供，则驾驶员眼睛中点（处于坐姿驾驶位置，参见 EN 16186-1）与文件之间的距离不应超过 $900\mathrm{mm}$。

注：关于在最大距离 $900\mathrm{mm}$ 下读取的纸质文件的最小字符高度，请参见 EN 894–2。

# 6.1.3 清洁活动造成的损坏抵抗力

操作元件的标记不应因清洁剂而变得难以辨认。

注：可接受的清洁剂清单通常由制造商提供。

# 6.1.4 防止污垢堆积的设计

深度大于$_{0,5\mathrm{mm}}$的刻痕应受到保护，以防止污垢堆积，从而保持其可读性，例如通过覆盖或密封。

# 6.1.5 标签

如果提供纯文本标签，则适用以下规定：

函数“0n”用罗马数字“I”表示；函数“0ff”用阿拉伯数字“0”表示；有关纯文本标记，请参阅 9.2.1 和 9.3。

# 6.2 显示器的特性

# 6.2.1 模拟和字母数字显示器的使用

通常，字母数字显示器应仅在需要精确的离散信息且所呈现的值在足够长的时间内保持可见以便读取时使用，即它们不会持续变化。否则，应使用模拟或图形显示器，请参阅 [9]。

# 6.2.2 显示阵列的要求

如果需要定期监控模拟或图形显示器以检查条件是否为“正常”，则应布置这些显示器，以便当仪表指示正常运行状态时，所有指针都对齐。

注意 参见 [9] 和 [10] 获取人机工程学方面的信息。

# 6.2.3 指针和刻度要求

通常应使用指针相对于固定刻度移动，而不是反过来。

# 6.3 控制器的特性

# 6.3 控制器的特性

# 6.3.1 一般原则

# 6.3.1.1 功能专用接口

接口应针对驱动程序执行的功能而设计，例如通过不同的形状、颜色或位置。

控件可以组合多个相关功能。

相关的驾驶任务应决定是否组合功能，例如用于牵引力和制动力的组合杆。

# 6.3.1.2 控制原则

位置相关的控制应是首选，而非时间相关的控制。

213 - 辅助台牵引力/制动组合控制器、远程控制台控制以及 037 - 直接制动应为时间相关。

# 6.3.1.3 操作方向

控制的操作方向应与其相关控制系统的行为一致。

# 6.3.1.4 隔离装置的位置指示

如果隔离装置显示其位置，例如通过手柄方向或标记，则适用以下规则：

a) ${\mathrm{I}}=0{\mathrm{n}}$ 或运行中；$0=0$ ff 或未运行。
b) 如果该装置安装在可见管道上的截止阀，则截止阀的位置应参考管道方向：打开 $\mathbf{\tau}=\mathbf{\tau}$ 与管道对齐，关闭 $\mathbf{\tau}=\mathbf{\tau}$ 与管道垂直。
c) 对于检查制动面板的正常运行，正常运行的位置应为垂直。需要根据 d) 进行标记。
d) 在设计限制的情况下，规则 b 和 c 可以被永久标签取代。

分配器隔离装置可能偏离规则 b；参见 EN 15355。

制动管和主储液管的直角和斜角截止阀也可能偏离规则 b；参见 EN 14601。

对于非对称截止阀，手柄的垂直位置应向下。

# 6.3.1.5 控制的可读性

控制应具有刻度（触觉）和/或照明（视觉），以便识别其操作位置（对于具有刻度的控制使用触觉，对于非刻度控制使用视觉）。如果控制具有刻度，则刻度应精细且精确，以用于驾驶目的。

# 6.3.1.6 仪表的可读性

有关刻度，请参考 EN 894-2 中关于视觉显示器识别的要求。

# 6.3.2 设计标准

# 6.3.2.1 形状识别

以下功能的控制应采用以下形状：

蘑菇形用于 010 - 紧急制动；
带球的杠杆用于 025 - 打磨；
带圆柱体的杠杆用于 016 - 受电弓；
杠杆用于 038 - 外部警报喇叭；
按钮用于 021、022 和 023 - 车门；
按钮用于 012 - 列车无线电紧急呼叫。

# 6.3.2.2 ATP 控制的触觉编码

013、014 和 015 - ATP 控制应具有不同的形状，以便于触觉识别其功能。

# 6.3.2.3 颜色

# 6.3.2.3.1 通用

在驾驶时由驾驶员操作的控制装置应相对于仪表台表面具有颜色区分。可以采用符合 RAL 840-HR 标准或同等标准的 RAL 9004、9011、9017 或 7016、7021、7024 范围内的黑色或灰色。

驾驶室内控制装置的标记和符号应与背景形成高对比度，例如，可以使用 RAL 9003、9010 和 9016 用于控制装置的标记和符号，RAL 9005 可用于底色。

# 6.3.2.3.2 红色

仅在发生安全关键故障或紧急情况时操作的控制装置及其相关指示器应采用红色 (RAL 3000、3001、3002、3020 或同等颜色)。

# 6.3.2.3.3 颜色：黄色

如果需要突出显示某个控制装置，例如在频繁使用以执行规定的常规程序时，可以在该元件或相邻表面使用黄色（例如 RAL 1003、1004、1018、1021、1023）。

# 6.3.2.3.4 不重要元件的颜色

为了避免视觉干扰，不重要的（例如：灯光开关、插座盖）或很少操作或用于维护目的的控制装置或操作设备应涂成白色、黑色、灰色、金属色（未涂层）或中性颜色（与周围环境相比）。

# 6.3.2.4 控制设计的稳健性

控制装置应设计成能够承受不利的环境条件和过度的机械应力（例如：饮用、饮食、灰尘、操作过程中的力作用（例如：调车、联结）以及恐慌情况）。这些因素不应影响其可操作性。

6.3.3 DAC 的总体特性、外部灯光控制和远程控制

# 6.3.3.1 驾驶员活动控制

工作台上应至少有一个用于 DAC 功能的控制元件，脚踏板上应至少有一个。

# 6.3.3.2 外部灯光控制

027 - 外部灯光（前照灯和示廓灯）的控制装置应至少控制车厢相邻车辆端部的外部灯光。车辆的前照灯和示廓灯应从正常驾驶位置控制。304 - 尾灯的控制装置应位于驾驶室内。

# 6.3.3.3 无线遥控

根据 EN 50239 标准，从“手动模式”切换到“无线遥控模式”的切换装置可以位于驾驶室内。

# 6.4 指示器的特性

# 6.4.1 可读性

所有指示灯应设计成在自然光或人工光照条件下（包括偶然光照）都能正确读取。

# 6.4.2 警告设计原则

# 6.4.2.1 通用

警告的设计应遵循以下原则：

驾驶室内听觉和视觉警告应具有鲜明特征，并根据其功能、紧急程度和重要性具有适当的响度和音质和/或光强度；听觉和视觉警告不应不必要地分散驾驶员对正常驾驶职责的注意力；
听觉和视觉警告在含义上应保持一致；
听觉信息应满足以下所有要求：每条听觉信息应与驾驶室内所有其他听觉信息区分开；
在驾驶室内所有适用驾驶位置和所有驾驶条件下均可听到；
— 听觉警告在触发时不得对驾驶员造成听觉不适。

注：有关听觉和视觉警告，请参阅 EN 16186–3。

# 6.4.2.2 听觉警告层级

至少对于通过单个通道提供的警告，应存在听觉警告层级，使得最重要的警告在触发并持续到取消或确认之前，将抑制掉重要性较低的听觉警告。

# 6.4.3 车内相关声学信号的可听性

车内由声学信号产生的可听信息应至少比在与警报主音调频率对应的一倍八分频程内的车内噪声高 $\mathrm{L}\mathrm{p}\mathrm{A}=6$ dB。用于在三分之一八分频程频率内比较警报的车内噪声应是在符合 EN 15892 或 ISO 3381 规定的列车最大运行速度下测量的。

# 6.4.4 扬声器音量

扬声器音量应可通过驾驶室内的控制装置进行调节。预设的最小可听级别定义于 6.4.3。

# 7 显示器和控制装置的位置

# 7 显示器和控制装置的位置

# 7.1 通用定位规则

# 7.1.1 驾驶员台设计

驾驶员台设计应允许一名驾驶员操作。

驾驶员台应根据附录 B 设计。

如果需要辅助台，应将其放置在侧壁上或侧壁附近。

# 7.1.2 人体工程学方面

应应用人体工程学原理来优化驾驶室内的布置，考虑以下因素：

a) 控制装置和仪表在可见性、可达性和所需力量方面的理想位置；
b) 源于熟悉现有设计的限制；
c) 由于驾驶室空间物理/技术要求造成的限制。

注 1：以上适用于正常驾驶以及由列车故障通常引起的合理可预见的苛刻场景。

控制装置的操作和仪表/显示器的查看不应过于疲劳，应考虑到驾驶员的强度和生物力学特性，以及本标准第 1 部分中描述的驾驶员的人体测量范围。

注 2：有关力量、重复性和姿势的更多信息，请参阅 EN 1005（所有部分），有关显示器的信息，请参阅 EN 894–2。

# 7.1.3 设备位置原则

驾驶室内的设备应按照以下原则进行布置：

a) 重要性原则 – 对安全高效运行最关键的显示器和控制装置应位于最易触及的位置，例如制动、牵引、喇叭的控制装置。
b) 使用频率原则 – 最常使用的显示器和控制装置应位于最易触及的位置，例如制动、DAC、信号的控制装置。
c) 功能原则 – 具有密切相关功能的显示器和控制装置应位于彼此靠近的位置。
d) 使用顺序原则 – 按照顺序使用的显示器和控制装置应位于彼此靠近的位置，并且其布局应与操作顺序逻辑相关。

为了在驾驶过程中能够轻松掌握和查看所有与安全相关的和/或经常使用的设备，不得允许与安全无关的元素阻碍或妨碍对安全元素的访问。

在驾驶过程中不需要的元素不应位于驾驶员台的正常区域（参见附录 A）。

为了避免驾驶员的注意力不必要地从观察线路分散，图 A.1 中的触及范围仅应包含在驾驶或危险情况下所需的控制装置和信息，并且图 A.2 中的首选视野应仅包含在驾驶或危险情况下所需的控制装置和信息。

触及范围和首选视野内仅应提供操作所需的必要信息。这些区域内不应有任何文字、标志或其他制造商的广告。

控制装置和显示器的位置应考虑到驾驶员所需的头部和眼睛运动量，旨在最大限度地提高驾驶员对轨道和信号的视觉集中度。

如果 TCMS 已开启，以下信息应始终在主驾驶台显示：

007 和 008 - 制动信息；
用于监控列车控制系统（驾驶室信号、004 - CCD）的信号方面信息；
时刻表（006 - ETD 或其他方式）。

如果驾驶室未激活，信息仅可应要求显示。

一组元素中的布置应与列车的运行行为一致（例如，前进、后退或左、右）。

# 7.1.4 侧窗驾驶位置

如果预见有侧窗驾驶位置（例如辅助台），该位置应允许驾驶员查看主台的制动和速度信息。这可以通过站立姿势下的头部移动来实现，但不得离开该位置。

# 7.1.5 空间限制

在空间受限的情况下，超出附件 B 中规定的显示器或仪表（控制、指示器等）可以放置在水平线之上（参见图 A.2），前提是不影响前方可见性（符合 EN 16186-1 标准）。

在空间受限的调车机车或带有前连通道和侧驾驶室的 EMU/DMU 中，在驾驶室内使用的控制装置应按照本标准进行定向，并且至少应提供相同的功能。方向功能（033、034、035）可以组合成一个旋转开关。

# 7.1.6 与本标准位置不同的元件定位

对于与本标准位置不同的元件定位，应考虑任务分析。

注：任务分析，包括姿势评估，已在 EUDD 计划中被使用，并作为本标准建议的来源。

# 7.2 显示器的定位

# 7.2.1 显示器位置和方向

显示表面应尽可能与驾驶员的视线垂直，并且避免直接或反射眩光。

至少以下显示器：

001 – TRD；
002 – TDD；
004 – CDD；
006 – ETD（如果适用）；

应设计为从正常驾驶位置的 $500\mathrm{mm}$ 至 $1000\mathrm{mm}$ 范围内观看。
它们应放置在不干扰驾驶室其他设备操作的位置。

# 7.2.2 优先视野范围

7.1.3 中确定的重要信息应根据图 A.2 位于仪表盘上的优先视野范围内。如果需要评估，应使用基于 EN 16186-1 中定义的坐姿高个驾驶员参考视点的图纸进行。

# 7.2.3 ATP信号信息定位

速度和004 - ETCS信号信息应位于优先视野范围内（见图A.2），符合TSI CCS标准的B类车厢信号信息应位于该范围内。

001 - 列车无线电 – 以及如果提供，CCTV和符合TSI CCS标准的B类车厢信号系统 – 可以放置在优先视野范围之外。

# 7.2.4 传统ATP系统的集成

如果集成传统ATP系统，则可以增大显示器之间的距离，以便在相邻显示器之间安装ATP-驾驶员界面，或者可以将这些传统组件安装在显示区域的上方，同时遵守图A.2中规定的首选视野范围以及EN 16186-1规定的前方可见性要求。

# 7.3 控制装置的位置

# 7.3.1 驾驶员台控制装置的可触及性

存在三个可触及范围，定义了以下三个区域：正常、扩展和最大，见图 A.1。

有关要素的定义和应用，请参阅附录 B 和附录 C。单个控制装置的位置是指其在中心位置时的中心点。

a) 正常：所有具有高重要性和/或高使用频率和/或长时间使用的控制装置，在坐姿和，如果适用，站姿下均应位于符合本标准的身体测量要求的正常可触及范围内。这包括可以通过前臂扫动即可触及的区域。在该区域内，应至少包含要素 019、020、032a 或 032b、037 的控制装置和信息。b) 扩展：重要性较低和/或使用频率较低的控制装置，应位于扩展可触及范围内，该范围包括在上臂远离正常条件时以及可能包括肩部推力的情况。该区域包括正常区域，应至少包含要素 013、014、015、016、017、018、021、022、023、025、026、027、033、034、035、038、040 的控制装置和信息，以及正常区域的要素。要素 024、028 和 029 也应位于该区域。c) 最大：驾驶员在坐姿下可以通过移动身体即可触及的控制装置。该区域包括正常区域和扩展区域，应至少包含以下位于驾驶员台上的控制装置和信息：001、002、004、006、009、010、012、030、036、101、102、103、104、105、106、107、108、109、114、115。对于并非设计用于频繁停车的车辆，要素 021、022、023 也可以位于该区域。要素 102、103、104、105、106、107、108、109、114、115 也可以位于驾驶员台下方。

注：测量基于 CEN/TR 16823 中给出的欧洲身体测量数据。

# 7.3.2 控制装置分组

# 7.3.2.1 总体

与同一功能相关的控制装置应组合或在驾驶员台面上分组在一起。
每个组中的控制装置数量应限制在三个。

# 7.3.2.2 车门控制装置分组

021、022 和 023 – 与车门相关的驾驶员台面上的控制装置应组合在一起或集成到一个组合元件中。这些元件的位置应反映相关单元侧面。

# 7.3.2.3 行进方向控制装置分组

033、034 和 035 – 与行进方向相关的控制装置应组合在一起放置在驾驶台面上，或集成到一个组合元件中。这些元件的位置应反映相关的行进方向。

# 7.3.2.4 列车自动防护（ATP）控制装置分组

013、014 和 015 – 列车自动防护（ATP）控制装置应组合在一起。

# 7.3.2.5 进一步分组示例

控制装置进一步分组的示例包括：

7.3.2.6 联结控制装置；
7.3.2.7 暖通空调控制装置；
7.3.2.8 前风挡刮水/清洗控制装置；
7.3.2.9 弓形/主开关控制装置等。

# 7.3.3 手部分配

对于列车，气动制动装置（032a - 自动制动或 032b - 牵引制动控制器）应位于驾驶员台的右侧。 这样，左手可以自由进行其他操作（例如，020 - 牵引动态制动控制器，001 - 列车无线电，013、014 和 015 ATC/ATP，016 - 受电弓，017 - 主断路器，012 - 列车无线电紧急呼叫按钮等）。

注：对于英国和爱尔兰，请参阅附录 F。

# 7.3.4 可访问性

一个元件的可访问性不应被另一个元件阻碍。

# 7.3.5 元件同步操作

在加速和制动时均可操作的元件应布置成可以用双手触及的方式；这些元件包括 025 - 撒砂控制，026 - 牵引单元自动制动释放，027 - 外部前灯和 029 - 阅读区及驾驶室照明。

# 7.3.6 误操作风险

控制元件的位置和分组应尽量减少误操作的风险。

# 7.3.7 特定控制元件的位置

# 7.3.7.1 概述

在桌面整合允许的情况下，控制元件应放置在桌面之上或延伸区域，而不是放置在桌面下方的控制台。如果 104、105、106、107 和 108 – HVAC 控制、103 – 中央控制台照明以及 109 – 压力保护控制可以从坐姿访问，则可以将其放置在桌面下方。

# 7.3.7.2 自动速度控制

019 - 自动速度控制应靠近 020 - 牵引/动轮制动杆。如果存在 32b - 单一组合牵引/制动控制器，则此要求可能不适用（参见图 B.2）。它应与位置相关联。

# 7.3.7.3 司机牵引和制动控制

如果牵引力及/或制动力是通过操纵杆（组合式或分离式）设置的，则“牵引力”应通过向前推操纵杆来增加，而“制动力”应通过将操纵杆向司机拉近来增加。对于提供的紧急制动位置，应有一个明显区别于操纵杆其他位置的刻度。

司机 032a - 自动制动手柄，020 - 牵引/动轮制动控制器和 032b - 组合牵引/制动元件应与位置相关联。

注：对于英国和爱尔兰，请参阅附录 F。

# 7.3.7.4 紧急制动控制

驾驶室内应至少提供一个紧急制动控制 010 – 紧急制动控制，以便司机从其驾驶位置以及任何其他授权人员从驾驶员助手位置能够触及。

# 7.3.7.5 制动管超压控制

安装了 009 – 制动管超压控制时，应尽可能将其布置在制动管压力信息附近。或者，可以这样布置制动管超压功能，即在操作该元件时，相关信息位于视线范围内。

# 7.3.7.6 公共广播控制

如果需要公共广播/乘客信息系统，则应在附录 A 定义的最大区域内设置用于公告的控制，以及在以下情况下：

手动系统：触发信息的控制；
自动系统：抑制信息的控制。

# 7.3.8 驾驶时使用但未位于驾驶员台面的控制装置

从坐姿操作的驾驶时使用的控制装置，但非用于快速和精准操作的必需装置，可位于驾驶员腿部空间旁边的垂直表面上（见附录 B）。

如果暖通空调控制装置可以从坐姿操作，则可以将其放置在台面下方。

为了在不分散驾驶员对轨道系统的注意力的情况下进行快速和精准的操作，驾驶员腿部空间内可以使用脚踏控制装置（例如踏板）。脚踏控制元件不得超过四个。

在除 DAC 以外的脚踏控制装置旁边，应留出两个空隙，每个空隙最小宽度为 140 毫米，以便驾驶员在坐姿时可以休息双脚，而不会触碰到任何这些控制装置，除了 DAC。

# 7.3.9 仅在静止时操作的控制装置

# 7.3.9.1 一般

仅在静止时操作的控制装置应根据图 A.1 位于三个可及范围之外。

# 7.3.9.2 ATP系统和DAC的隔离

从驾驶位置无法触及520、543——隔离ATP系统和隔离503——DAC。

# 7.3.9.3 车门控制位置

为了监控外部车门，如果驾驶员需要从主要驾驶位置移动到侧窗以查看平台安装的设备或向后查看列车，那么适用于该侧的车门控制装置应位于每个侧窗处。

# 8 驾驶室、显示器、控制装置和指示器的照明

# 8.1 驾驶室照明

驾驶室照明应符合 prEN 13272-1 标准。

# 8.2 阅读区域照明

阅读区域照明应配备元件 029。它应独立于驾驶室照明，并且应可通过元件 039 进行调节。

# 8.3 仪表照明

仪表照明应根据元件 028 提供。如果提供，它应独立于驾驶室照明，并且应根据元件 104 进行调节。照度值的范围应为 0.3 lx 至 30 lx。

# 8.4 防止干扰驾驶员

当提供附加灯具时（例如为第二人提供的灯具），这些灯具不应在灯具的正常工作位置使驾驶员眩目。

# 8.5 禁止绿色照明

为了防止与外部运行信号产生危险的混淆，驾驶室内不允许使用绿色灯光或绿色照明，除非是现有的B类车厢信号系统（符合TSI CCS标准）。

*   **UIC Standards & Documents** - Standards developed by the International Railway Union (UIC), often focused on practical railway operations and harmonization.
*   **Other Documents/Reports/Guidelines** - Research reports, guidelines, and recommendations from various organizations.

*   **Technical Recommendation Driver Machine Interfaces** (UNIFE and UIC).



**Key Themes & What This List Covers:**

*   **Driver Machine Interface (DMI):**  A *huge* focus, especially with the UIC 612 series and the ETCS specification. This covers how the driver interacts with the train's controls and displays.
*   **Ergonomics:**  Standards like ISO 3411 and ISO 9241 are critical for ensuring driver comfort, safety, and efficiency.
*   **Safety Signage & Symbols:**  ISO 7010, ISO 3864, and ISO 7000 are all about clear communication of hazards and instructions.
*   **Railway Harmonization:** The UIC standards aim to create consistent practices across different railway networks.
*   **TSI Compliance:**  Many of these standards are referenced to demonstrate compliance with the European Technical Specifications for Interoperability.
